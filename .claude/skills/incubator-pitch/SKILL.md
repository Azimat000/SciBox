# Питч ИОН: заявка в инкубатор и презентация

Этот скилл главный для любой работы над презентацией и заявкой ИОН. Он задаёт порядок, требования отбора и правила честности, а по каждому разделу подключает профильный скилл.

## 1. Сначала прочитать

- `PRODUCT.md`, `DESIGN.md`: что за продукт, цвета и шрифты бренда.
- `docs/ROADMAP.md`, `docs/HANDOFF.md`: что реально сделано (это «трекшн» и техническая готовность).
- `references/itpark-reglament.md`: правила отбора ИТ-парка с источниками.
- `references/deck-structure.md`: разделы презентации, что в каждом и какой скилл применять.
- `deliverables/pitch/README.md`: где лежит текущая презентация, исходники и сборка.

## 2. Какой скилл на какой раздел

| Раздел | Скилл |
|---|---|
| Сюжет всей презентации, речь на 3/5/10 минут, вопросы экспертов, репетиция | `startup-pitch` |
| Рынок: TAM/SAM/SOM сверху вниз и снизу вверх, диапазоны | `market-sizing` |
| Конкуренты: таблица возможностей, цены, слабые места | `startup-competitors` |
| Позиционирование, УТП, «чем мы отличаемся» | `startup-positioning` |
| Бизнес-модель, lean canvas, финансовый прогноз, эксперименты проверки | `startup-design` |
| Цены, тарифы, гипотезы монетизации | `pricing-strategy` |
| Проверка готовой презентации: оценка, слабые места, возражения инвесторов | `pitch-deck-reviewer` |
| Сборка файла .pptx, проверка картинками | `anthropic-skills:pptx` (глобальный) |

Профильный скилл даёт метод; факты и цифры для ИОН берутся по правилам ниже.

## 3. Правила честности (не нарушать)

1. Не выдумывать пользователей, пилоты, продажи, отзывы, логотипы партнёров (PRODUCT.md, «Evidence on Hand»). Сейчас: продукт разработан, реальных пользователей, пилотов и продаж нет. Это говорится прямо.
2. Каждая цифра рынка со ссылкой на источник и годом (ИСИЭЗ ВШЭ, Росстат, Минобрнауки, отчётность компаний). Оценки помечаются словом «оценка» и показывают расчёт.
3. Монетизация пока гипотеза (D-016: тарифов в продукте нет). В презентации это «гипотезы для проверки в инкубаторе», а не план продаж.
4. В интерфейсе сайта слово «бесплатно» не используется (D-129); в презентации можно писать «для соискателей без оплаты».
5. Роли команды и регалии сверять с открытыми источниками и с самим человеком; спорное отмечать для пользователя.

## 4. Структура и формат

- Название: ИОН, «Инновации, образование, наука». Все три сферы равноправны, у каждой свой пример: наука (научные должности, конкурсы, гранты), образование (ППС, аспирантура, магистратура, стажировки), инновации (R&D-компании, технопарки, проектная работа, трансфер технологий).
- Презентация к защите 12–16 слайдов основной части плюс приложение. Речь 5–7 минут: эксперты ИТ-парка слушают первую защиту, дают советы, на второй день защита повторяется.
- Форма заявки ИТ-парка принимает только PDF, DOC или DOCX до 20 МБ: к .pptx всегда собирать PDF.

## 5. Оформление (бренд ИОН)

- Цвета: тёмно-синий `1C2C66` (основной, как в логотипе), глубокий `121E4D`, винный `722F37` (акцент, как кисточка шапочки), бумага `FFFFFF`, подложка `F6F4F1`, линии `E4E1DC`, текст `1F1D1A` и `5D5A55`. Винный только как редкий акцент.
- Шрифты в .pptx: заголовки Times New Roman, текст Calibri (есть в Office, кириллица, проверка в LibreOffice совпадает по ширине).
- Мотив: «чип» раздела над заголовком и треугольник знаний И · О · Н. Без цветных полос по краю, без подчёркиваний заголовков, без градиентного текста.
- Каждый слайд: одна мысль в заголовке, визуальный элемент (скриншот, схема, крупная цифра, таблица), источник мелко внизу.
- Скриншоты только настоящего сайта с демо-данными; демо-организации вымышленные, и это видно по подписи.

## 6. Проверка перед сдачей

1. `markitdown` по .pptx: опечатки, порядок, нет заглушек.
2. `validate.py` из скилла pptx.
3. Отрисовать все слайды в картинки и посмотреть каждый: нет вылезания текста, наложений, мелких полей.
4. `pitch-deck-reviewer`: оценка и список доработок; исправить существенное.
5. Сверить с критериями ИТ-парка (раздел 2 в `references/itpark-reglament.md`): на каждый критерий есть слайд.
