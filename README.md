# SciBox

Сайт вакансий для науки в России. Организации публикуют научные должности, места на кафедрах, аспирантуру и постдоки, учёные ищут их и откликаются научным профилем вместо обычного резюме. Всё работает на вашем компьютере, а показать сайт другому человеку можно по ссылке (`make share`, см. ниже). Организации и люди в демо-данных вымышленные, города настоящие.

Название рабочее и хранится в одном месте: `config/product.json`.

## Что нужно поставить

| Программа | Версия | Зачем |
|---|---|---|
| Docker Desktop | 29 или новее | база данных и почтовый ящик для тестовых писем |
| Go | 1.26 | сервер |
| Node.js | 26 (с npm 11) | сайт и тесты |

Порты, которые должны быть свободны: 5173 (сайт), 8080 (сервер), 5433 (база), 8025 и 1025 (почта). Для сквозных тестов ещё 5174 и 8090.

## Первый запуск

Откройте Docker Desktop и дождитесь, пока он запустится. Затем в папке проекта загрузите демо-данные:

```bash
make db-reset
```

И запустите сайт:

```bash
make dev
```

Через полминуты всё готово:

- сайт: http://localhost:5173
- почта, куда приходят все письма сайта: http://localhost:8025
- проверка, что сервер жив: http://127.0.0.1:8080/api/health

Остановить: Ctrl+C в окне, где запущен `make dev`. Команда `make db-reset` возвращает демо-данные в исходный вид, всё созданное вами при этом пропадёт.

## Показать сайт коллеге по ссылке

Сайт может работать на вашем Mac, а коллега откроет его по обычной ссылке из любого города. Сначала один раз загрузите демо-данные (`make db-reset`, если ещё не делали), затем:

```bash
make share
```

Через полминуты в окне появится строка «Ссылка для коллеги: https://…». Её и отправляйте. Пока команда работает, Mac не засыпает. Остановить показ: Ctrl+C.

Что нужно помнить:

- Сайт доступен, только пока Mac включён, подключён к интернету и команда `make share` работает. Если закрыть крышку без зарядки, Mac уснёт, и ссылка перестанет открываться.
- По умолчанию ссылку выдаёт localhost.run, ставить ничего не нужно. Бесплатно он примерно раз в полчаса-час меняет адрес, и старая ссылка перестаёт открываться. Когда это случается, `make share` пишет новую ссылку в окно и показывает уведомление в углу экрана: перешлите её коллеге. Оборвавшийся туннель команда переподключает сама.
- Стабильнее работает российский tuna.am. Поставьте его один раз командой `brew install yuccastream/tap/tuna`, и `make share` сам будет пользоваться им.
- Письма сайта коллеге не придут: они складываются в http://localhost:8025 на вашем Mac. Проще всего дать коллеге демо-аккаунт из таблицы ниже. Если коллега зарегистрировался сам, откройте его письмо у себя и перешлите ему ссылку из письма.
- Коллега работает с теми же данными, что и вы в `make dev`. Вернуть демо-данные в исходный вид: `make db-reset`.

## Дорожка «я учёный»

1. Откройте главную. Введите тему или город в строку поиска, например «мерзлота» или «Томск», и нажмите «Найти». На странице вакансий слева фильтры: область науки, регион, требуемая степень, срок подачи и другие.
2. Зарегистрируйтесь («Зарегистрироваться» в шапке) на любую выдуманную почту. Письмо со ссылкой придёт в http://localhost:8025, откройте его и нажмите ссылку: почта подтверждена, вы уже вошли.
3. Заполните профиль: «Мой профиль» → «Изменить основное». Степень, специальности ВАК, ORCID, h-index; публикации можно добавить по DOI, поля заполнятся сами, а журнал подберётся из справочника SCImago, и у публикации появится квартиль (Q1–Q4). В блоке «Кто видит профиль» выберите «Все» или «Организации», тогда вас найдут в каталоге учёных.
4. Откройте вакансию и нажмите «Откликнуться». Профиль подставится сам, допишите сопроводительное письмо, при желании приложите PDF и попросите рекомендательное письмо: рекомендателю придёт одноразовая ссылка.
5. Следите за откликами в «Мои отклики». Когда организация пригласит на собеседование, придёт уведомление (колокольчик в шапке) и письмо; время можно подтвердить или предложить другое.
6. В «Избранном» лежат отмеченные вакансии, подходящие вам по профилю, сохранённые поиски с письмами о новых вакансиях и календарь сроков подачи. За 7 дней и за 1 день до срока приходит напоминание.

Быстрее всего посмотреть готовое: войдите как `dmitry.korolev@demo.example.ru`.

## Дорожка «я организация»

1. Зарегистрируйтесь и переключите режим в шапке на «Нанимаю».
2. Создайте организацию: «Организация» → «Создать организацию». Добавьте подразделения (лаборатории, кафедры) и пригласите коллег по почте. Роли: владелец, кадровик (видит все вакансии и отклики), руководитель подразделения (видит только своё).
3. Создайте вакансию в «Мои вакансии». Для черновика хватит названия и должности, для публикации форма подскажет, чего не хватает. Опубликованную вакансию сразу находят в поиске.
4. Отклики приходят в раздел «Отклики». В отклике видны письмо, файлы, рекомендательные письма и снимок профиля на момент отклика. Можно пригласить на собеседование, отправить свои контакты или попросить контакты кандидата, принять или отказать.
5. В «Каталоге учёных» ищите людей сами и зовите их на свои вакансии кнопкой «Пригласить на вакансию».

Быстрее всего посмотреть готовое: войдите как `olga.kuznetsova@demo.example.ru` и включите «Нанимаю».

## Проверки

Все тесты сервера и сайта с проверкой покрытия (около 4 минут, Docker должен работать):

```bash
make test
```

Сквозные сценарии в настоящем браузере (Playwright, около минуты). Они поднимают свою копию сайта на отдельной базе `scibox_e2e`, поэтому ваши данные и запущенный `make dev` не трогают:

```bash
make e2e
```

Сценарии лежат в `e2e/tests`: учёный регистрируется, подтверждает почту, заполняет профиль, откликается, организация приглашает его на собеседование и из каталога на другую вакансию; новая организация публикует вакансию, и гость находит её поиском. Каждый проходит на экране компьютера и телефона. Отчёт о последнем прогоне: `e2e/report/index.html`.

## Если что-то не работает

- «port is already allocated» или «address already in use»: порт занят другой программой. Закройте её или остановите прошлый запуск сайта.
- Сайт открылся, но пишет, что сервер не отвечает: проверьте, что Docker Desktop запущен, и перезапустите `make dev`.
- Письмо не пришло: письма уходят из очереди раз в пару секунд, обновите страницу http://localhost:8025.

## Где что лежит

- `server/` сервер на Go: API, база PostgreSQL, письма.
- `web/` сайт на React. Все тексты интерфейса в `web/src/i18n/ru.ts`.
- `e2e/` сквозные тесты Playwright.
- `docs/` память проекта: план срезов, решения, архитектура, термины. Начинать чтение с `docs/ARCHITECTURE.md`.
- `PRODUCT.md` и `DESIGN.md` описание продукта и визуального стиля.
