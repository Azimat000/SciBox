Формат: `D-NNN · дата · кто решил` — решение. *Почему:* ...

## Интервью 2026-10-02 (сессия планирования)

### Продукт и роли
- **D-001 · 2026-10-02 · пользователь** — Продукт: сервис поиска работы и публикации вакансий в научной сфере России. Рабочее имя SciBox (может смениться, имя хранится в одной настройке). *Почему:* нет специализированного сервиса; госпортал ученые-исследователи.рф только реестр.
- **D-002 · пользователь** — Роли в первой версии: соискатель, организация, научный руководитель. Модератора нет.
- **D-003 · пользователь** — Публиковать вакансии может любой. Проверки организаций, значка «Подтверждена» и галочек нет вообще.
- **D-004 · пользователь** — Один аккаунт на человека, несколько ролей; переключатель «Ищу работу / Нанимаю». *Почему:* профессор может и нанимать, и искать.
- **D-005 · пользователь** — В организации несколько сотрудников по приглашению. Руководитель подразделения видит отклики только на свои вакансии.
- **D-006 · пользователь** — Типы позиций: научные должности; ППС; аспирантура / постдоки / стажировки / магистратура; управление и инновационная инфраструктура.

### Профиль и отклик
- **D-007 · пользователь** — Профиль: степень и звание (ВАК), идентификаторы и метрики (ORCID, SPIN, Scopus, WoS, h-index), публикации и гранты, преподавание.
- **D-008 · пользователь** — Публикации: вручную + автозаполнение по DOI через Crossref. Импорт из ORCID позже.
- **D-009 · пользователь** — Отклик всегда одинаковый: профиль + сопроводительное + файлы + авто-PDF CV из профиля. Особой логики конкурсов в отклике нет.
- **D-010 · пользователь** — Приватность профиля выбирает соискатель: скрыт / виден организациям / публичный + «открыт к предложениям».
- **D-011 · пользователь** — После отклика: статусы, приглашения от организаций, уведомления (на сайте + письмом). Приглашение на выбор организации: собеседование с датой/временем/ссылкой или адресом; контакты; форма, где соискатель оставляет контакты и удобное время. Чата нет.

### Поиск и разделы
- **D-012 · пользователь** — Фильтры: область науки, регион и формат, условия, требования и организация.
- **D-013 · пользователь** — Доп. разделы: избранное и подписки, каталог учёных, простые страницы организаций и подразделений (без новостей и отзывов). Аналитики для организаций нет.
- **D-014 · пользователь** — Из зарубежного опыта берём: рекомендательные письма через платформу (как MathJobs), карьерные уровни R1–R4 (как EURAXESS), дедлайны с напоминаниями, подбор «подходящие вам» по правилам. Зарплата НЕ обязательна.
- **D-015 · пользователь** — Госпортал ученые-исследователи.рф пока не учитываем.
- **D-016 · пользователь** — Главная: лендинг + поиск + свежие вакансии. Монетизации и тарифов нет, всё бесплатно.

### Техника и процесс
- **D-017 · пользователь** — Стек: React-сайт + отдельный сервер на Go. Детали (Vite, TS, React Router, TanStack Query; chi, pgx + sqlc, goose) выбрал Claude.
- **D-018 · пользователь** — База: PostgreSQL через Docker. Письма локально: Mailpit (выбрал Claude).
- **D-019 · пользователь** — Вход: почта + пароль. ORCID / Яндекс / ВК / Госуслуги показываем кнопками «скоро».
- **D-020 · пользователь** — Только локальный запуск. Публикацию в интернет решим позже (тогда хостинг в РФ из-за 152-ФЗ).
- **D-021 · пользователь** — Язык: русский, тексты в словарях с заделом на английский.
- **D-022 · пользователь** — Демо-данные: вымышленные организации и люди, реальные города.
- **D-023 · пользователь** — Телефон и компьютер равноценны, проверяем оба.
- **D-024 · пользователь** — Визуальный стиль: «смесь, покажи варианты» — в срезе 2 показать 2–3 направления.
- **D-025 · пользователь** — Средние срезы (~13), память = файлы в `docs/` + команда `/next-slice`, git со снимком в конце каждого среза (только локально, без GitHub).

- **D-026 · 2026-10-02 · пользователь** — Покрытие кода тестами больше 90%, в важных местах ещё выше. Конкретизация (Claude): ≥ 90% строк везде, ≥ 97% строк в критичных зонах (+ ≥ 95% ветвлений на фронтенде), табличные тесты на каждую ветку прав и статусов. Порог проверяется в `make test`. Подробности в `docs/TESTING.md`. *Почему:* на сервисе персональные данные и решения о найме, ошибки в правах и приватности недопустимы.
