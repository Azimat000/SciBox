# Проверка названия для сайта научной карьеры

Процедура для России. Подготовлена 16 октября 2026 года для SciBox. Применять перед выбором нового названия, подачей заявки на товарный знак и публичным запуском.

Подтверждённые пользователем услуги: вакансии, подбор сотрудников и доступ к платформе. Предпочтение: короткое русское название с научной ассоциацией. Свои курсы, научные исследования и самостоятельный мессенджер в эту проверку не входят.

## Как принимать решение

Для каждого этапа ставить один из четырёх статусов:

- **Пройдено в указанном объёме**: записаны запросы, дата и источник результата.
- **Есть препятствие**: найдено совпадение или ограничение, которое нужно оценить по существу.
- **Не завершено**: источник недоступен, проверена только часть написаний или не получены документы.
- **Не применяется**: есть объяснение, почему этап не относится к услугам проекта.

«Ничего не найдено» означает результат конкретного запроса. Это не заменяет проверку сходства и не даёт гарантии регистрации. Не усреднять юридические риски в общий балл: хороший внешний вид названия не компенсирует конфликт прав.

## 1. Зафиксировать название и услуги

Записать:

- слово кириллицей, предполагаемое ударение, произношение и расшифровку;
- основное написание латиницей и другие естественные транслитерации;
- варианты с пробелами, дефисами, приставками и окончаниями;
- полное и сокращённое наименование будущего ООО;
- нынешние услуги и отдельно действительно запланированные услуги;
- кто будет владельцем товарного знака и доменов.

Для сравнения со знаками составить перечень конкретных услуг. Для этого проекта основные направления проверки — класс 35 МКТУ (в том числе подбор персонала и соответствующие услуги по вакансиям) и класс 42 (предоставление программной платформы как услуги, если это соответствует модели работы). Класс 9 оценивать при выпуске отдельного загружаемого ПО. Класс 41 оценивать при собственном обучении. Не добавлять класс только потому, что на сайте есть сведения о такой деятельности.

МКТУ — система группировки товаров и услуг. Совпадение номера класса не доказывает конфликт, а разные номера не исключают его. Сравнивать сами услуги, их потребителей, назначение и способы оказания. Окончательный перечень для заявки согласовать с правилами Роспатента.

## 2. Проверить слово и оформление

Разделить четыре объекта: само слово, расшифровку, логотип и графику сайта.

- Не искать «регистрацию авторского права на слово» как замену товарному знаку.
- Оценить, не взято ли оригинальное название известного произведения, персонаж или чужой узнаваемый образ.
- Для логотипа проверить источник, автора и документы о передаче прав либо условия лицензии.
- Для шрифтов, иконок и иллюстраций сохранить лицензии и проверить условия использования в логотипе и на сайте.
- Зафиксировать ограничения для фирменного наименования: официальные названия и обозначения, государственные и общественные организации, специальные требования к словам и деятельности.

Нестандартный шрифт или рисунок не следует считать способом устранить конфликт самого слова. Расшифровка аббревиатуры тоже не является автоматическим разрешением.

## 3. Проверить товарные знаки

Первый источник: [поисковая платформа Роспатента](https://searchplatform.rospatent.gov.ru/trademarks). Проверять национальные регистрации, опубликованные заявки и международные регистрации с охраной в России. При необходимости дополнять открытыми реестрами ФИПС, бюллетенями и WIPO.

Последовательно выполнить:

1. Точное совпадение кириллицей без ограничения классом.
2. Точное совпадение всех естественных латинских написаний.
3. Поиск сходных по звучанию, виду и смыслу обозначений, в том числе составных знаков с тем же сильным элементом.
4. Повторный отбор по фактическим услугам проекта и связанным услугам.
5. Проверку общеизвестных знаков и иных оснований отказа, которые не сводятся к одинаковому написанию.

Для каждого существенного результата открыть карточку и сохранить:

| Поле | Что записать |
|---|---|
| Идентификатор | Номер заявки и регистрации; прямой адрес карточки |
| Обозначение | Текст и изображение, если знак комбинированный |
| Владелец | Правообладатель либо заявитель |
| Даты | Подача, приоритет, регистрация, окончание охраны |
| Статус | Текущий официальный статус и изменения прав |
| Территория | Есть ли охрана именно в РФ |
| Услуги | Конкретный перечень; одного номера класса недостаточно |
| Сходство | Что совпадает и может ли возникнуть смешение у потребителя |
| Доказательство | Документ, скриншот либо сохранённый результат и время проверки |

Если карточка недоступна, не переписывать данные вторичного агрегатора как первично подтверждённые. Отдельно отметить, что видно в официальной выдаче, что известно из другого источника и что осталось проверить.

## 4. Проверить ООО и фактических конкурентов

Источник для российских компаний: [ЕГРЮЛ/ЕГРИП ФНС](https://egrul.nalog.ru/).

1. Искать полное и сокращённое название по всей России, с вариантами написания.
2. Получить актуальные выписки по существенным совпадениям.
3. Сопоставить дату регистрации, действующий статус и виды деятельности.
4. Проверить фактические услуги на сайтах компаний: заявленные коды деятельности сами по себе не описывают весь бизнес.
5. Проверить сходные коммерческие обозначения действующих сервисов, даже если юридическое лицо называется иначе.
6. Сформулировать два отдельных вывода: допустимость наименования при регистрации ООО и риск его использования в конкретном бизнесе.

Не трактовать наличие одноимённого ООО как автоматический отказ ФНС. Не трактовать отсутствие точного совпадения в ЕГРЮЛ как разрешение на бренд.

Регистрация названия не заменяет остальных условий создания ООО: учредительных документов, адреса, органов управления и других обязательных сведений. Этот цикл проверяет именно название.

## 5. Проверить поиск, домены и вид названия

- Выполнить запросы по слову в кавычках, транслитерациям и сочетаниям с «работа», «вакансии», «наука», «образование», «платформа».
- Проверить фактические сайты и проекты; отделить юридический конфликт в РФ от неудобства в поисковой выдаче.
- Проверить нужные домены .ru и .рф через WHOIS/регистратора. Записать точный домен, результат и время. Отсутствие сайта не означает свободный домен.
- Проверить выбранные имена в нужных социальных сетях, если они входят в план запуска.
- Посмотреть слово в нынешнем шрифте сайта, на компьютере и на узком телефоне. Проверить чтение, длину, переносы, возможные опечатки и нежелательные ассоциации.
- Произнести вслух: «нашёл на …», «профиль в …», «вакансия на …». Решить, склоняется ли название и какое написание закрепить.

Доступность домена и аккаунта не подтверждает право на название. Не покупать домен, если решение о расходах ещё не принято владельцем проекта.

## 6. Подготовить решение и завершить проверку

Итоговая таблица для каждого кандидата:

| Этап | Статус | Источник / доказательство | Что осталось |
|---|---|---|---|
| Название и услуги |  |  |  |
| Слово, логотип и лицензии |  |  |  |
| Точные товарные знаки |  |  |  |
| Сходные знаки и заявки |  |  |  |
| Международная охрана в РФ |  |  |  |
| ЕГРЮЛ и фирменные наименования |  |  |  |
| Действующие сервисы |  |  |  |
| Домены / нужные аккаунты |  |  |  |
| Шапка сайта и произношение |  |  |  |

В решении различать:

- **Отложить**: установлен существенный конфликт либо коммерческий риск неприемлем.
- **Кандидат для углублённой проверки**: первичный отсев пройден, но остались обязательные пробелы.
- **Можно готовить подачу**: проверены все нужные источники и варианты, выполнено сравнение услуг, документированы оставшиеся риски.
- **Знак зарегистрирован**: есть официальное решение и регистрационная запись с нужным владельцем, обозначением и перечнем услуг.

До публичного запуска и непосредственно перед подачей повторить поиск по свежим заявкам и статусам существенных совпадений. Подать заявку на нужное обозначение и услуги от выбранного владельца. Получение номера заявки само по себе не означает регистрацию и не устраняет права третьих лиц.

Если выявлен спорный похожий знак, перед расходами на бренд получить предметное заключение патентного поверенного с сопоставлением обозначений и услуг. Передавать ему результаты запросов и карточки, а не только просьбу «проверьте название».

После подачи отслеживать запросы экспертизы и сроки ответа. После регистрации сохранять документы, следить за сроком охраны и повторять проверку при расширении услуг, изменении названия или выходе в другую страну.
