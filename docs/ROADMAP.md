## [x] 15. Анонимный режим и «скрыть от моей организации»

## [x] 31. Резюме PDF: без жёлтой полоски и без акцента на h-index
- Из плашки с именем убрать жёлтую полоску (маркер внизу синей шапки): жёлтый в дизайне только у сроков (D-132).
- Убрать полосу с крупными числами h-index под шапкой: показатель есть не у всех (преподаватели, административные сотрудники и другие). h-index остаётся обычной строкой среди идентификаторов («h-index: РИНЦ 9, Scopus 12») и только если хоть один указан; пустой профиль без показателей не оставляет пустого места.
- Проверить, не осталось ли тех же акцентов в шапке страницы профиля (`ProfileView`): если да, показать пользователю и решить отдельно (по заданию правка касается резюме PDF).
- Скиллы: `golang-testing`; PDF проверить глазами (собрать резюме для профиля с h-index, без h-index, анонимного и очень длинного).
- Готово, когда: в PDF нет жёлтого и полосы чисел, строка h-index обычная; у профиля без h-index нет пустой полосы; `cv_test` и тесты профиля обновлены, `make test` зелёный.

## [x] 23. Файлы: хранилище S3, проверка на вирусы, потоковая загрузка
