Один срез = одна сессия. Запуск следующего: `/next-slice`. Конкретного: `/next-slice 7`.
Статусы: `[ ]` не начат · `[~]` в работе / частично · `[x]` готов.
Порядок работы внутри среза и критерии готовности: см. `.claude/skills/next-slice/SKILL.md`.

## [x] 0. Каркас памяти
git, файлы памяти в `docs/`, скилл `/next-slice`, хук SessionStart, правила в `CLAUDE.md`.

## [x] 1. Фундамент проекта
- `/impeccable init` → `PRODUCT.md` (с секцией `## Stack`: React+Vite+TS / Go / PostgreSQL; решения в DECISIONS).
- Структура `web/` (Vite + React + TypeScript, React Router, TanStack Query, словарь i18n `ru`) и `server/` (Go, chi, pgx + sqlc, goose).
- `docker-compose.yml`: PostgreSQL 16, Mailpit. `Makefile`: `dev`, `test`, `seed`, `migrate`, `db-reset`.
- `/api/health` проверяет БД; фронтенд показывает, что сервер отвечает. Первая миграция.
- Название продукта в одной настройке (и на сервере, и на фронте).
- Тестовая инфраструктура по `docs/TESTING.md`: Go-тесты с настоящей тестовой БД в Docker, Vitest + Testing Library + coverage-v8 с порогами, `scripts/coverage-check` для Go; `make test` падает при покрытии ниже порога.
- Готово, когда: `make dev` поднимает всё, `make test` зелёный и проверяет пороги покрытия, страница открывается.

## [x] 2. Визуальный мир и дизайн-система
- `impeccable` new-work: 2–3 визуальных направления (картинками, если доступна генерация), пользователь выбирает. Пользователь хочет «смесь, покажи варианты».
- `DESIGN.md`, токены, шрифты с кириллицей (не Inter).
- Компоненты: кнопки, поля, select/combobox, теги, карточки, модальные окна, тосты, пустые состояния, скелетоны загрузки.
- Каркас: шапка, переключатель «Ищу работу / Нанимаю», подвал, мобильное меню; служебная `/styleguide`.
- Готово, когда: стиль выбран пользователем, компоненты на `/styleguide` проходят audit, desktop+mobile.

## [x] 3. Аккаунты
- Регистрация (почта+пароль, согласие на обработку ПДн по 152-ФЗ, черновик политики), подтверждение почты, вход/выход, сброс пароля. Письма в Mailpit.
- Сессии в cookie + таблица сессий, argon2id, ограничение частоты попыток входа.
- Настройки аккаунта; кнопки «скоро» для ORCID / Яндекс / ВК / Госуслуги.
- Готово, когда: полный цикл регистрации и сброса пароля работает в браузере, письма видны в Mailpit.

## [x] 4. Организации и подразделения
- Создание организации (тип: вуз, НИИ / институт РАН, научный центр, компания с R&D, технопарк / инновационная инфраструктура, другое), город, сайт, описание.
- Подразделения (кафедра, лаборатория, отдел, ЦКП) с руководителем и научными темами.
- Приглашение сотрудников по почте; роли: владелец, кадровик (все вакансии), руководитель подразделения (только свои).
- Публичные страницы организации и подразделения со списком вакансий.

## [x] 5. Справочники и вакансии
- Справочники (сиды из официальных источников через `web-researcher`, источник записать): специальности ВАК, регионы РФ, карьерные уровни R1–R4, типы позиций, источники финансирования, степени и звания.
- Форма вакансии с полями по типу (научная / ППС / аспирантура-постдок / управление): ставка, зарплата (необязательна), срок договора, формат, жильё, требования, дедлайн, отметка «конкурс».
- Жизненный цикл: черновик → опубликована → закрыта / архив. Страница вакансии, «Мои вакансии».

## [x] 6. Поиск вакансий
- Фильтры: область науки, регион, формат, условия (зарплата, ставка, срок, финансирование), требуемая степень, уровень, тип организации, тип позиции, дедлайн. Фильтры в URL.
- Полнотекстовый поиск по-русски (tsvector russian + pg_trgm), сортировка, пагинация.
- Демо-данные: ~30 вымышленных организаций, ~200 вакансий, реальные города.
- Пока нет лендинга, `/` = поиск.

## [x] 7. Профиль учёного
- Степень, звание, специальность ВАК, диссертация; ORCID, SPIN, Scopus ID, WoS ID + h-index по базам (вручную).
- Публикации: вручную и по DOI (Crossref API, без ключа; при недоступности остаётся ручной ввод). Гранты, патенты, преподавание, опыт, образование.
- Приватность: скрыт / виден организациям / публичный; «открыт к предложениям». Публичная страница профиля. Авто-PDF CV.

## [ ] 8. Отклик и рекомендательные письма
- Отклик: профиль автоматически + сопроводительное письмо + PDF-файлы + авто-CV.
- Рекомендации: запрос рекомендателю по почте, загрузка письма по одноразовой ссылке без аккаунта; видит организация, не видит соискатель.
- «Мои отклики» со статусами. Центр уведомлений (колокольчик) + письма в Mailpit.

## [ ] 9. Разбор откликов организацией
- Отклики по вакансии, карточка кандидата, статусы: отправлен → просмотрен → приглашение → отказ / принят.
- Приглашение трёх видов: собеседование (дата, время, ссылка/адрес; соискатель подтверждает или предлагает другое время), контакты организации, просьба оставить контакты и удобное время.
- Уведомления обеим сторонам.

- Каталог с фильтрами с учётом приватности. Организация приглашает учёного на конкретную вакансию.
