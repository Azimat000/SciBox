# Срез 25: разбор своих правок (differential review)

Дата 2026-10-10. Метод: скилл `differential-review`, правки среза против `55b4c16` (конец среза 24) и промежуточного коммита среза. Объём: 17 пакетов, критичные зоны `notifications`, `jobs`, `resilience`, `config`, `crossref` (рядом с `profiles`), `blobstore`, `matching`.

## Что менялось и риск

| Часть | Риск | Почему |
|---|---|---|
| Очередь писем (`notifications/worker.go`, SQL) | высокий | меняет судьбу письма: когда повторять, когда отбросить, когда вернуть; ошибка даёт потерянные или двойные письма людям |
| Расписание (`jobs`, `job_runs`) | высокий | от него зависит, выполнятся ли уборка по срокам (152-ФЗ), стирание аккаунтов, рассылки |
| Предохранитель и ограничитель (`resilience`, Crossref, почта) | средний | ошибка в классификации сбоя открывает предохранитель зря или не открывает |
| Сборка (`cli`) | средний | один список задач для сервера и воркера; ошибка = задача не исполняется нигде |
| Удаление циклов `Run` и `RunCleanup` в семи пакетах | средний | удалён код, который исполнял уборку; проверено, что каждая задача есть в `cli/jobs.go` |
| Настройки (`config`) | низкий | три новые переменные, пределы проверяются |
| Скрипты (`dev.sh`, `share`, e2e) | низкий | запуск воркера |

## Удалённое и проверка git blame

Удалены `Worker.Run` (срез 8), `auth.Service.RunCleanup` (срез 3), `orgs.Service.RunCleanup` (срез 4), `httpguard.PostgresStore.RunCleanup` (срез 19), `retention.Service.Run` (срез 22), `matching.Service.Run` и `pass` (срез 11), `filework.Service.Run` (срез 23). Проверок прав, приватности или защиты среди них нет: это были циклы «раз в срок вызвать проход». Каждый проход вызывается из `cli/jobs.go`; тест `TestSeveralCopiesNeverSendTwice` исполняет настоящие задачи сборки. Служебные обёртки удалены вместе с тестами, содержание тестов (работа до отмены, переживание сбоя базы, запись в журнал) проверяет `jobs`.

## Находки

## Расчёт «радиуса»

- `newApp` (подпись не менялась) вызывают 3 теста; `newServices` вызывают `serve`, `runWorker`, `newApp` и новые тесты копий.
- `notifications.Stats` получила поля (литералы `Stats{}` в тестах продолжают работать); `Worker.Run` удалён (3 теста заменены).
- `crossref.Client` получил поле `Gate`; без него (nil) поведение прежнее; его вызывает один пакет `profiles` через интерфейс.
- Миграция только добавляет таблицу; откат проверен цепочкой `TestUpDownUp`.
