# Срез 11. Избранное, подписки, подбор, дедлайны

Статус: готов. 2026-10-03.

## Цель
Ищущий копит интересное и не пропускает сроки: добавляет вакансии в избранное, сохраняет поиск и получает письма о новых
вакансиях, видит «Подходящие вам» по понятным правилам (без ИИ), смотрит календарь сроков и получает напоминания.
Решения пользователя: D-104 (частота писем о поисках), D-105 (напоминания за 7 и за 1 день), D-106 (переключатели писем).
Просьба пользователя к срезу: без эмодзи, держать эталон дизайна (`DESIGN.md`) и UX/UI.

## Задачи

### Сервер
- Миграция `00011`: `favorites`, `saved_searches`, `deadline_reminders`, `notification_settings`.
- Новый пакет `internal/matching` (критичная зона, порог 97%): избранное, сохранённые поиски, «Подходящие вам» (чистые правила
  `rules.go`), календарь сроков, фоновая рассылка по поискам и напоминания о сроках (запускаются в процессе сервера раз в 5 минут).
- `notifications`: переключатели писем (`GET/PUT /api/notification-settings`); `Emit` не ставит письмо в очередь, если вид
  письма выключен (уведомление на сайте остаётся всегда).
- `vacancies`: разбор и запись условий поиска в адресе (`query.go`), отбор по моменту публикации и запрет запасного поиска
  для рассылок.

### Интерфейс
- Раздел `/favorites` из четырёх вкладок: «Избранное», «Подходящие» (`/matches`), «Поиски» (`/saved-searches`), «Сроки» (`/deadlines`).
- Закладка «В избранное» на записи вакансии и странице вакансии; «Сохранить поиск» в строке результатов поиска.
- Письма в настройках аккаунта: два переключателя.
- Состояния везде: загрузка, ошибка с повтором, пусто, длинные данные, не вошёл, профиль без областей науки.

### Данные
- Демо: у шести учёных избранное, часть со сроком в ближайшие дни, и семь сохранённых поисков с четырьмя частотами.

## Сделано

**Сервер**
- Избранное (D-107): добавить, убрать, номера для закладок, список с состояниями и отметкой об отклике, предел 200, защита от гонки.
- Сохранённые поиски (D-108): условия в каноническом виде, проверка теми же правилами, что в самом поиске, предел 20, частоты
  «сразу / раз в день / раз в неделю / не сообщать», возобновление после паузы без потока старого.
- Рассылка по поискам: граница «учтено до», запас в минуту, одно письмо со списком до 10 вакансий и «и ещё N», без запасного поиска
  «по похожим словам»; сбой поиска ничего не теряет; две одновременные рассылки не дают двух писем.
- «Подходящие вам» (D-109): общая группа специальностей обязательна, степень и звание не выше своих, баллы за специальность,
  уровень R, степень и регион; у каждой вакансии коды причин.
- Напоминания о сроке (D-110): за неделю и за сутки, не раньше 9:00 МСК, не откликнувшимся, один раз на срок, не тем, кто
  добавил вакансию только что.
- Календарь сроков, настройки писем (D-111), демо-данные (D-113).

**Интерфейс (D-112)**
- Четыре страницы раздела с вкладками; пункт меню «Избранное» текущий на всех.
- Закладка: сразу меняет состояние, при отказе сервера возвращает и объясняет; на телефоне стоит под текстом записи.
- «Избранное»: отметки «набор закончен» / «срок прошёл» / «вы откликнулись»; убранное остаётся строкой с «Вернуть».
- «Подходящие»: на что опирается подбор и причины под каждой вакансией словами.
- «Поиски»: условия тегами, частота меняется прямо в списке, «Переименовать», «Удалить» с подтверждением; ссылка из уведомления
  открывает поиск с новыми вакансиями вперёд.
- «Сроки»: повестка по месяцам, маркер у сроков в пределах недели.
- «Сохранить поиск»: окно с условиями, названием и частотой (на телефоне нижняя шторка).
- В настройках аккаунта раздел «Письма».
- Черновик политики конфиденциальности дополнен про избранное, поиски и письма (версия текста та же).
- Удалена заглушка «Раздел готовится»; `refreshApplications` теперь обновляет и подборку, избранное и сроки.

## Отступления от плана
- В подборке общий только раздел науки (первое число кода) не считается совпадением: в первом варианте у геолога было 119
  «подходящих» вакансий из всей естественной науки, после правки 46 по делу (D-109).
- «Календарь» сделан повесткой по месяцам и дням, не сеткой месяца: на телефоне сетка хуже читается. Файла `.ics` нет.
- Не запускали отдельно `/impeccable audit`, `/impeccable critique`, `web-design-guidelines`: они идут одним проходом по всему
  сайту в срезе 13 (долг в HANDOFF). Хук Impeccable замечаний не выдал; худший случай проверен вручную в браузере (см. ниже).
- Одинаковые сохранённые поиски не запрещены (только предел 20).
