## Что проверено
- **Откуда может прийти строка.** Только `PUT /api/profile` (поле `github_url`). Других записей в столбец нет (`UpdateProfileCore` вызывается из одного места). Периметр (`apierr.DecodeJSON` + `textsafe`) отвергает нулевой знак и невалидный UTF-8 до сервиса: `TestHTTPGitHubLinkWithNulIsRefusedAndKeepsTheSavedOne`.
- **Что делает разборщик.** Ручной разбор: только печатный ASCII без пробелов; схема `http(s)://` отрезается без учёта регистра; любой из `: @ ? # % \ ;` в остатке даёт отказ; хост ровно `github.com` или `www.github.com`; путь из одного сегмента; логин по правилам GitHub; служебные имена отвергаются. Результат всегда `https://github.com/<логин>`. Инвариант проверен фаззингом (≈900 тысяч запусков за 20 секунд без находок) и перебором 10 тысяч сочетаний.
- **Откуда читается.** `build` (страница, снимок отклика), `idFacts` (резюме), `to_jsonb(profiles)` (выгрузка), `DELETE FROM profiles` (стирание). Безымянная карточка собирается с нуля (`blindView`) и поля не копирует: `TestAnonymousProfileForStaffIsBlind` ищет в ответе логин и `github.com`.
- **Сайт.** В `href` попадает только значение, прошедшее `githubLogin` (строгое регулярное выражение), иначе выводится текстом без ссылки; `rel="noopener noreferrer nofollow"`, `target="_blank"`.
- **Совместимость.** Столбец с `DEFAULT ''`, прежняя версия сервера работает с новой базой (D-186). Старые снимки откликов поля не содержат; сайт и сервер это переносят (`github_url?`, тест `never puts a strange GitHub value into a link`).
