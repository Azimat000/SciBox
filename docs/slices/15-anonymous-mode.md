# Срез 15. Анонимный режим и «скрыть от моей организации»

Начат и готов 2026-10-11. Решения D-199…D-205 (записаны в `docs/DECISIONS.md`). Продуктовая очередь, первый срез после серверной (D-138).

## Цель

Две новые возможности приватности профиля учёного:
1. **Режим «Анонимно для организаций»**: сотрудники организаций видят научные данные (степень, звание, уровень R, специальности, h-index, счётчики публикаций и статей Q1–Q2), но не имя, не место работы, не город и регион, не идентификаторы, не названия публикаций и грантов, не контакты. Имя открывается организации, когда учёный сам откликнулся на её вакансию или ответил «Интересно» на её приглашение. Анонима можно приглашать.
2. **«Скрыть от организаций»**: учёный выбирает организации, чьи сотрудники не видят профиль ни в каком режиме.

## Карта мест, где профиль уходит наружу (риск среза)

| Место | Что было | Что делаем |
|---|---|---|
| Страница учёного `GET /api/scientists/{id}` | всё, что положено по режиму | по уровню раскрытия: нет / анонимно / полностью |
| Резюме PDF `GET /api/scientists/{id}/cv` | всё | только при полном раскрытии |
| Каталог `GET /api/scientists` | карточка с именем | анонимная карточка; анонимы не находятся по словам и региону, не сортируются по имени |
| Приглашение: проверка «профиль виден» | `CanView` | видимый аноним можно приглашать, скрытый от организации нельзя |
| Приглашение: ответ организации (`Offer.Scientist`, список «Отправленные») | имя | имя только если режим не анонимный или имя раскрыто |
| Уведомление и письмо сотрудникам «Ответил …» | имя | то же правило |
| Журнал действий организации (`subject` у `offer.sent/canceled`) | имя и номер аккаунта | у скрытого аноним: «Кандидат», без номера |
| Отклик (снимок профиля, D-079) | имя | без изменений: человек откликнулся сам; заодно имя раскрывается организации |
| Числа главной | профили публичного режима | без изменений (аноним не публичен) |
| Выгрузка своих данных, удаление аккаунта | — | новые таблицы входят в выгрузку и стираются каскадом |

## Задачи

### Сервер
- [x] Миграция 00027: режим `anonymous` в `profiles.visibility` (и `visibility_before_deletion`), таблицы `profile_hidden_orgs` и `profile_reveals`.
- [x] `privacy`: режим `Anonymous`, уровень раскрытия `None/Anonymous/Full`, `Viewer.Blocked/Revealed`; таблица «кто × режим × скрыт ли × раскрыт ли».
- [x] `profiles`: анонимный вид страницы, резюме только полному, каталог (SQL: скрытость, раскрытие, поиск), список «скрыто от», добавить и убрать организацию (до 50).
- [x] `applications`: раскрытие имени при отправке отклика.
- [x] `offers`: приглашение аноним/скрытому, раскрытие при «Интересно», имя в списках и уведомлениях.
- [x] `audit`: аноним в журнале.
- [x] Демо-данные: анонимные профили, скрытые организации, раскрытие.

### Интерфейс
- [x] Панель приватности: четвёртый режим, блок «Скрыть от организаций» (поиск организации, список, убрать).
- [x] Анонимная карточка в каталоге и на странице учёного; без «Скачать резюме»; пояснение «имя откроется, когда…».
- [x] Окно приглашения и «Отправленные приглашения» для анонима; тексты в `ru.ts`; пустые/загрузка/ошибка.

- Утечка имени: ни в одном ответе, письме, уведомлении, журнале, CV.

## Сделано

- Миграция `00027`: режим `anonymous`, таблицы `profile_hidden_orgs` и `profile_reveals` (D-199…D-201, D-205).
- `privacy`: `Disclose` (закрыт / анонимная карточка / полностью), `Viewer.Blocked/Revealed`, `MaskedLabel`; новый пакет `career` (уровень R1–R4, D-206; правило вынесено из `matching`).
- `profiles`: анонимный вид из разрешённого списка (`mask`), каталог (SQL по строкам: скрытость, раскрытие, поиск по словам и региону не берёт анонимов, имя и должность в SQL не отдаются), резюме анонима 404, «скрыть от организаций» (список, скрыть, вернуть, предел 50), время правки анонима с точностью до дня.
- `applications`: отклик раскрывает имя организации вакансии. `offers`: анонима приглашать можно, имя не отдаётся ни в приглашении, ни в списке, ни в уведомлении и письме; «Интересно» раскрывает имя пригласившей организации; скрытый от организации профиль приглашать нельзя. `audit`: «Анонимный кандидат» без номера аккаунта. `dataexport`: два новых раздела выгрузки.
- Сайт: четвёртый режим, блок «Скрыть от организаций» (поиск организации, скрыть, вернуть), анонимная страница учёного, анонимная карточка в каталоге и в «Отправленных», подсказка в окне приглашения.
- Демо-данные: два анонимных профиля (Фёдоров, Лебедева), Жукова скрыла профиль от Южного института морской биологии.

## Отступления от плана

- Уровень «R2» из примера карточки в профиле не хранится: считается по степени и званию (D-206); дорожная карта упоминала уровень, поля для него в профиле нет.
- Слова поиска и регион анонима не находят (D-203): иначе по выдаче можно было бы узнавать скрытое. Этого в плане не было, добавлено как следствие требования «не по чему узнать».
- Скрытие от организации сильнее раскрытия имени, а отклик скрытой организации разрешён (D-200, D-201).
