# Срез 12: Лендинг

Статус: готов. 2026-10-03 — 2026-10-04.

## Цель
Главная страница `/` рассказывает, что это за сайт, обеим сторонам (учёным и организациям), даёт строку поиска, свежие вакансии и настоящие числа из базы. Сам поиск живёт на `/vacancies` (D-069 снимается).

## Как читаем задачу
Лендинг = режим Persuade, но мир уже выбран: «Журнал» (D-035). Строим в нём, без карточных сеток, без «героя-метрики», без надписи над заголовком (kicker), без выдуманных цифр и логотипов. Картинок нет (D-037).
Design Read: лендинг для учёных и организаций России, язык «научного журнала», диалы: разнообразие 5, движение 3, плотность 3.

## Задачи

### Сервер
- Один публичный запрос `GET /api/landing`: сколько открытых вакансий, сколько организаций их ищут людей, сколько учёных видит гость в каталоге, открытые вакансии по областям науки и по видам позиций. Пакет `internal/landing`.
- Тесты вместе с кодом (порог 90%, не критичная зона: наружу идут только счётчики).

### Интерфейс (`web/src/features/landing`)
- `/` = `LandingPage`; `/vacancies` = поиск (как был).
- Блоки: заголовок и строка поиска (уходит на `/vacancies?q=&region=`) с числами из базы; колонка «по областям науки» и «по видам позиций» (ссылки в поиск с числами); свежие вакансии (6 штук, готовая запись вакансии); две дорожки «Если вы ищете место» / «Если вы набираете людей»; «Устроено под науку» (список определений).
- Состояния: загрузка, ошибка с повтором, нет вакансий, нет чисел (страница работает без них), вошедший человек (кнопки ведут в профиль и организацию), длинные данные.
- Тексты только в `ru.ts` (раздел `landing`), цвета и размеры через токены.

### Данные
- Новых демо-данных не нужно: числа считаются по тем, что есть (30 организаций, ~216 вакансий, 14 профилей).

- Решения D-114…D-117.

## Отступления от плана
- Оглавление (области и виды позиций) стоит в разметке после свежих вакансий и только на компьютере поднимается вправо от заголовка (сетка всей страницы): так на телефоне вакансии идут раньше длинного оглавления.
- Размер заголовка уменьшен с 3,75 до 3,125 rem: первая фраза должна влезать в одну строку колонки.
- Полные `/impeccable audit`, `/impeccable critique` и `break-ui` не делались (входят в срез 13, как и для прежних срезов); сделаны детектор Impeccable (чисто), замеры и проверка в браузере.
