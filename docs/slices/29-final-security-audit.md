## Что сделано

### Сервер (Go)
- `auth`: неделимые лимиты (`reserve`, `refund`, `LockRateKey`), сеть /64, привязка ссылки подтверждения (`issueConfirmToken`, `ConfirmEmail`, `ConfirmedElsewhereError`), абсолютный срок сессии, гашение ожидающей смены почты, письмо старому адресу, неактивные аккаунты (`inactive.go`), нейтральное приветствие в письме подтверждения, строгий разбор почты, чтение с чужого сайта отвергается.
- `textsafe` (новый пакет, критичная зона): проверка текста; периметр, `DecodeJSON`, multipart, поиск, рассылка по поискам.
- `httpguard`: срок долгой передачи только вошедшему или после проверки ссылки (`ExtendTransfer`), `NetworkKey`.
- `profiles`: замок счётчика DOI и предел просмотров чужих профилей; `orgs`, `applications`, `vacancies`, `offers`, `references`, `dataexport`: замок счётчика; `orgs`: гашение приглашений ушедшего владельца; `applications`: `Precheck`, политика `apply_upload`; `notifications`: срок записи итога на каждое письмо; `httpcache`: паника сборки; `vacancies`/`profiles`: ключ кеша; `crossref`, `files`: обманные знаки; `httpapi`: `/api/health`.
- Миграции 00025 (привязка ссылки) и 00026 (неактивные аккаунты) только добавляют (`TestNewMigrationsOnlyExpandTheSchema`).
- Фаззинг: 12 целей (`*/fuzz_test.go`).
### Интерфейс
- Страница подтверждения почты ведёт на выбор пароля, если ссылку открыли не в браузере регистрации (`ConfirmEmailPage`, `ResetPasswordPage`, строка `afterConfirmLead`); `mailtoHref` для контактной почты.
### Боевой стенд
- `log_parameter_max_length=0` у базы, пункты в `docs/DEPLOY.md` (раздел 11); второе имя `scibox.test` в `deploy/caddy/Caddyfile.local` для сканеров (Java не передаёт SNI для имени без точки).
