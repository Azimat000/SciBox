Дата: 2026-10-15. Область: все изменения среза против метки `slice-37` (рабочее дерево до коммита). Пакеты: `chat` (новые `events.go`, `tools.go`, `links.go`, `backfill.go`, `http_tools.go`; правки `closure.go`, `service.go`, `chat.go`, `list.go`, `http.go`), `applications` и `offers` (вызовы строк о событиях, поле `chat`, проверка блокировки), `notifications` (поле `email_messages`), `erasure`, `dataexport`, `httpapi` (периметр), `cli` (`chats backfill`, `release`), миграция `00032`, запросы sqlc, `seed`. Риск HIGH: права, приватность анонимного учёного, удаление данных. Стратегия SURGICAL: критичные пути целиком, остальное выборочно.

## Базовый контекст

- Удалённых строк с проверками нет. `git diff` по `applications`, `offers`, `notifications`, `erasure`, `chat` показывает только замену вызовов (`CancelOpenInvitations` и `CancelOpenInterviews` теперь возвращают закрытые приглашения, `s.now()` вынесен в переменную) и добавление. Правило проверок прав осталось единственным (`access.Actor.Can`): новые адреса спрашивают `orgs.ActorOf` и `access`, своих проверок ролей в `chat` нет (`canUseTemplates` комбинирует только ответы `Actor.Can`).
- Порядок замков (D-230) сохранён: во всех вызовах `chat.Record` отклик или приглашение уже изменены (держат свой замок), потом переписка; `Block` и `Unblock` берут только замки переписок по возрастанию номера; шаблоны берут только счётчик `LockRateKey`.
- Миграция только добавляет (`safety_test` зелёный).

## Покрытие изменённого кода тестами

Каждый новый и изменённый файл проверен тестом на падение при нарушении: порядок строк, данные строк, права, блокировка и гонки, перенос, выгрузка, стирание, контракт. Непокрытого изменённого кода в критичных зонах нет (цифры в отчёте среза, раздел «Покрытие»).

- `applications`: изменены 7 методов (`Apply`, `Get`, `Mine`, `Withdraw`, `Decide`, `Invite`, `CancelInvitation`, `AcceptProposal`, `Answer`, `Candidates`, `markViewed`), все с тестами на строку; новый зависимый импорт `chat`.

## Уровень уверенности

Высокий для прав, анонимности, откатов и гонок блокировки: каждое направление закрыто тестом, который падает при нарушении (мутации вручную: убрана строка решения из `Decide`, блокировка выключена из состояния переписки; обе ловятся тестами).
