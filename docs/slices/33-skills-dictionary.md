# Срез 33: навыки из справочника с подсказками

Статус: в работе (2026-10-14). Решения: D-136 (два списка навыков), D-211 (источник), D-212 (свои навыки), D-186 (миграции только добавляют). Скиллы: golang-database, golang-security, golang-testing, sharp-edges; интерфейс: impeccable, break-ui.

## Цель
Научные и общие навыки в профиле выбираются поиском: человек печатает, под полем подсказки из справочника, выбранные навыки стоят чипами. Нет нужного: в конце списка «Не нашли? Добавить «…»». Профиль по-прежнему хранит строки (`research_skills`, `general_skills`).

## Решения пользователя (2026-10-14)
- Источник: свой справочник, составленный командой (готового русского с открытой лицензией нет: ESCO и O*NET без русского, hh.ru запрещает копировать). Исследование `web-researcher` записано в `docs/REFERENCE.md`.
- Свои навыки человека остаются только в его профиле, в чужих подсказках не показываются (до модерации, срез 30).

## Задачи
Сервер
- миграция 00030: таблицы `skills` (навык: вид, группа, каноническое написание, ключ) и `skill_terms` (название и синонимы: ключ, слова, `tsvector`), индексы;
- пакет `internal/skills`: ключ сравнения (`Key`: регистр, «ё», тире, пробелы), разбор CSV, загрузка заменой целиком (как журналы), поиск (точное, начало, начало слова, словоформы, опечатки), HTTP `GET /api/skills`;
- файл справочника `internal/skills/data/skills.csv`, встроен в сервер; команда `scibox skills load`, строка в `reference_sources`;
- `profiles`: приведение навыков к каноническому написанию при сохранении, повторы без учёта регистра и «ё»;
- периметр: политика частоты, строка таблицы прав доступа.

Интерфейс
- `SkillsInput` получает подсказки (комбобокс WAI-ARIA, клавиатура, телефон), «Не нашли? Добавить «…»», состояния: загрузка, ошибка, пусто, полный список;
- тексты в `ru.ts`.

Данные: навыки у демо-людей.

## Проверяем
- каждый ярус поиска отдельной строкой таблицы; опечатки; ё; регистр; пределы; без входа 401;
- сохранение профиля: канонизация, синонимы сводятся, повторы убираются, неизвестное остаётся как есть, прежние навыки не пропадают;
- замена справочника не ломает профили (они хранят строки);
- качество встроенного файла (повторов нет, длины, группы).

## Риски
- Справочник составлен вручную: может быть неполным; «Не нашли? Добавить» закрывает это, расширение идёт правкой одного CSV.
- Канонизация при сохранении меняет написание, которое человек ввёл: показываем это сразу после сохранения, а в подсказке синоним помечен.

## Готово, когда
- [ ] оба поля навыков работают через подсказки на компьютере и телефоне;
- [ ] есть «Не нашли? Добавить»;
- [ ] существующие навыки в профилях не потеряны и не продублированы;
- [ ] источник справочника и лицензия записаны (`reference_sources`, `docs/REFERENCE.md`);
- [ ] тесты и `make test` зелёные.
