## Удалённый защитный код

- `auth.meta`: разбор `RemoteAddr` заменён на `httpguard.ClientIP`. Без доверенных прокси результат тот же (адрес соединения), без периметра в цепочке тоже (запасной путь через `RemoteAddr`). Доказательство: `TestClientIP`, `TestPerimeter/client address behind a trusted proxy reaches sessions` (без прокси заголовок игнорируется).
- `WebHandler`: убраны `nosniff` и `Referrer-Policy`. Теперь их ставит `Perimeter` для всех ответов роутера; `WebHandler` подключается только через `httpapi.NewRouter` (`Deps.Web`). Доказательство: `TestPerimeter/security headers…/site page`.
- Срок `ReadHeaderTimeout` 10 с сохранён, добавлены остальные.

## Радиус влияния

- `httpguard.ClientIP`: 1 место вызова (`auth.meta`), через него 4 обработчика: регистрация, вход, сброс пароля, повтор письма (лимиты по IP, D-042) и запись `sessions.ip`.
- `Perimeter` и `Throttle` стоят на всех запросах роутера: тест проходит по 88 адресам.

## Сценарии атаки и вывод

1. **Подделка адреса через X-Forwarded-For.** Без `SCIBOX_TRUSTED_PROXIES` заголовок не читается. С ним заголовок читается справа налево до первого недоверенного адреса, поэтому подставленный слева адрес не работает (`forged left part is ignored`). Остаётся риск, если доверенный прокси передаёт заголовок посетителя без дописывания. Для `make share` поведение туннелей tuna и localhost.run не документировано: последствие ограничено обходом своего лимита в демо-показе. Записано в D-141.
2. **Доверие всему интернету.** `0.0.0.0/0` и `::/0` отвергаются при запуске (`TestParseProxies`).
3. **Обход лимита частоты сменой адреса.** Вошедший считается по аккаунту. IPv6 считается по сети /64 (`TestGuestKey`).
4. **Отказ счётчиков.** При сбое таблицы `rate_counters` ответ 500, а не пропуск без счёта (`TestThrottleStoreFailure`). Следствие: сбой этой таблицы кладёт публичный поиск. Принято (I-09: сбой базы не превращается в «успех»).
5. **Огромное тело.** `Content-Length` больше лимита даёт 413 до обработчика; тело без длины обрезается на лимите. Тест проходит по всем адресам настоящей сборки двумя пользователями. Мутация «лимит 1000 байт» даёт 48 падений: проверка действительно видит чтение.
6. **Медленный клиент.** Заголовки обрезаются по сроку (`TestSlowHeadersAreCut`), тело на обычном адресе тоже, долгий срок только у адресов загрузки и выдачи файлов (`TestSlowTransferGetsItsOwnDeadline`).
7. **Нулевой или отрицательный срок в настройке.** Заменяется сроком по умолчанию, а не «без срока» (`TestNewServerSetsEveryTimeout`).
