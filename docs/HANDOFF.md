# HANDOFF: записка следующей сессии

Обновлено: 2026-10-03, после среза 10.

## Где остановились
Срез 10 «Каталог учёных и приглашения» готов. `/scientists`: каталог (слова, область науки, регион, степень, звание, «открыт к предложениям», h-index, порядок, страницы) по правилам приватности. Организация в режиме «Нанимаю» приглашает учёного на вакансию из каталога или со страницы учёного. Учёный отвечает «Интересно» / «Не сейчас» на `/offers/:id`; организация видит ответы на `/sent-offers` и может отозвать приглашение. Уведомления и письма обеим сторонам. Отчёт: `docs/slices/10-catalog-offers.md`, решения D-095…D-103.

## Как запустить
- `make dev`: база + Mailpit, миграции, сервер (127.0.0.1:8080) и сайт (http://localhost:5173). Письма: http://localhost:8025. Остановка: Ctrl+C.
- `make db-reset`: пересоздать базу и демо-данные (30 организаций, 216 вакансий, 17 людей, 14 профилей, 14 откликов, 6 приглашений на вакансии). Вход: `olga.kuznetsova@demo.example.ru` (владелец Байкальского института: 8 откликов, 3 отправленных приглашения во всех состояниях), `ksenia.lebedeva@…` (учёная: приглашение ждёт ответа), `dmitry.korolev@…` (ответил «Не сейчас», плюс отклики), `alina.guseva@…` (ответила «Интересно»), `igor.tarasov@…`, `natalia.zhukova@…`, `anton.vasilev@…` (приглашения ждут ответа); все `@demo.example.ru`, один пароль в `server/seed/seed.go`. Видны в каталоге 11 профилей (7 публичных, 4 «организациям»; скрытые 3).
- `make test`: всё с проверкой покрытия (около 4 минут; сам поднимает Docker-контейнеры).
- Встроенный браузер Claude не запускает `make dev` из «Документов»: сервер и Vite запускать через Bash в фоне (`cd server && go build -o bin/scibox ./cmd/api && ./bin/scibox serve`, `cd web && npm run dev -- --strictPort`), затем `preview_start` с `url`. Остановка: `pkill -f "bin/scibox serve"; pkill -f "vite --strictPort"`. Вход делать запросом `fetch('/api/auth/login', …)` через `javascript_tool`; режим «Нанимаю» включается `localStorage.setItem('scibox.role','employer')`. Для телефона `resize_window` с пресетом `mobile`, потом вернуть `desktop`. Свои размеры вроде 1440 после перехода на другую страницу дают кривой скриншот: перед снимком лучше `desktop`, а клики делать через `javascript_tool` (`element.click()`).

## Известные проблемы и долги
- Не делали полный `/impeccable critique`, `/impeccable audit`, `break-ui` и `web-design-guidelines` для срезов 3, 4, 5, 7, 8, 9, 10 и для поиска (только детектор, замеры и худший случай в браузере). Всё это входит в срез 13.
- Каталог ищет на лету без индекса (D-098): при тысячах профилей нужна таблица текста, как у вакансий. Русский стеммер не сводит «Седов» и «Седова»: такие запросы находятся через «похожие слова». Нет поиска по организации учёного и по публикациям.
- Приглашение на вакансию: нет напоминаний, нет фильтра по вакансии на странице `/sent-offers` (сервер его умеет), отклик «по приглашению» ничем не помечен ни у соискателя, ни у организации. Приглашать нельзя больше 20 раз в сутки с аккаунта (D-099). Нет отдельной ссылки «пригласить» на странице вакансии.
- Решение по отклику окончательное (D-088); истории смены статусов нет; нет поиска по имени кандидата, нет массовых действий. Кто отправил приглашение к отклику, не показывается (`created_by` хранится).
- Приглашение к отклику: соискатель отвечает один раз; нет файла календаря (.ics). Время только московское (D-089). Вкладки статусов откликов на телефоне занимают три строки.
- Отправленный отклик нельзя править, только отозвать и подать заново. Письмо рекомендателя нельзя заменить. Нет напоминания рекомендателю.
- Письма-уведомления нельзя отключить. «Просмотрен» тоже уходит письмом.
- Публичные адреса `/api/recommendations/*` и публичный каталог `/api/scientists` не ограничены по IP. Файлы откликов лежат в базе (D-080), на вирусы не сканируются.
- Профиль: нет подсказки о заполненности, фото, импорта из ORCID (D-008). «Виден организациям» = любой сотрудник любой организации (D-072).
- Почта по SMTP без шифрования (только локально, D-020). Нельзя сменить почту, удалить аккаунт и организацию кнопкой (D-043, D-051).
- Запасной поиск вакансий «по похожим словам» без индекса (D-065). Заголовок вкладки всегда «SciBox».
- Текст `/privacy` черновик (нужна проверка юриста). Тёмной темы нет. `mail` покрыт на 90,9%.
- Нет копирования вакансии и истории изменений; в списке на странице организации до 50 вакансий без листания.

## Неочевидные вещи
- Порт базы **5433** (D-028). Тесты с базой: общий помощник `internal/testkit`; в `applications` помощники в `helpers_test.go`, в `offers` тоже (`newWorld`, `scientist`, `snap`). Пакет `profiles` не может использовать `testkit` (тот сам его импортирует): у него свои помощники. База в пакете общая, поэтому тесты каталога ищут по случайной метке (`marker()`): метка вроде `zq12x` попала бы под «похожие слова» чужих профилей. Критичные зоны сервера = имена пакетов в `server/coverage.conf` (D-033).
- Права: приглашения и отклики спрашивают `access` через `orgs.ActorOf` и `orgs.ScopeOf(perm)` (D-102); приватность профиля решает `privacy.CatalogModes` (каталог) и `CanView` (страница). Приглашающий всегда сотрудник, поэтому смотрит на профиль как `Viewer{Staff: true}`.
- `GET /api/scientists/{id}/offer-targets` отдаёт пустой список, а не 404, посторонним без организации (профиль публичный); для профиля «организациям» и скрытого у них 404.
- Уведомления: `notifications.Service.Emit(ctx, q, …)` в транзакции события; текст уходит и в письмо, переносы строк сохраняются. Контакты в уведомления организации не кладём.
- Тесты фронтенда: `stubApi` (`web/src/test/api.ts`), фикстуры `web/src/test/offers.ts`, `applications.ts`; даты форматируются с « г.»; в режиме «Нанимаю» тест ставит `localStorage` ключ `scibox.role`.
- Фронтенд: каталог подключает `features/search/search.css` (общий вид поиска); `FilterGroup` и `ScienceFilter` лежат в `ui/`; формы на `useForm` (мутация принимает поля аргументом, иначе TypeScript путается в круговой ссылке на `values`); `oxlint --deny-warnings` строгий.
- Записи разделов профиля: одна таблица `profile_items` с JSON; новое поле записи = `profiles.ItemFields` + `validateItem` + `web/src/features/profile/sections.ts` + `ru.ts`.
- `vacancy_view`: добавили колонку в `vacancies` — пересоздайте представление в новой миграции и `go tool sqlc generate`. sqlc: nullable `text` → `*string`, `timestamptz` в `SET x = @now` писать `@now::timestamptz`; скалярный подзапрос sqlc считает «не null», для необязательного значения брать `LEFT JOIN`.
- Название продукта: `config/product.json` (D-029). Цвета и размеры только через токены; тексты только в `src/i18n/ru.ts`.
- Демо-данные детерминированы по структуре; сроки подачи считаются от дня загрузки; приглашения демо-откликов и статусы ставятся напрямую в базе, а приглашения на вакансии (`seed/offers.go`) отправляет настоящий сервис.
