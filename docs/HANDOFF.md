## Неочевидные вещи
- **Блокировка**: `StateOf(application, offer, blocked)`; блокировка читается отдельным запросом после замка переписки (`IsChatBlocked`), иначе при ожидании замка подзапрос видит старый снимок. Приглашения перепроверяют блокировку после записи строки в переписку.
- **`OpenChat` при приглашении после отозванного отклика отвязывает отклик** (иначе переписка закрыта отзывом, пока приглашение ждёт ответа).
- **`CancelOpenInvitations` и `CancelOpenInterviews` возвращают закрытые приглашения**: по каждому пишется строка «отменено».
- **Тесты, которые вставляют отклики прямо в базу** (`w.application`), переписки сами не получают: строки пишет только настоящий сервис. В `cli` фикстура `f.chat()` берёт переписку настоящего отклика.
- Прежние: состояние приглашения считается по строкам ленты (`events.ts`, D-223); зона покрытия сайта `'src/features/chat/*.{ts,tsx}'`; на iCloud файлы проекта выгружаются (`dataless`), лечится `find web server deploy config -type f -flags +dataless -exec cat {} +`; зависимости сайта в `web/node_modules.nosync`; порт базы 5433; `preview_start` падает («getcwd»), `make dev` из терминала; `npx prettier` в `web/` не запускать; тексты только в `web/src/i18n/ru.ts`.
