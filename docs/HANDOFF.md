## Как запустить
- `make dev`: база + Mailpit, миграции **и загрузка справочника журналов**, сервер (127.0.0.1:8080) и сайт (http://localhost:5173). Письма: http://localhost:8025.
- `make db-reset`: всё заново (миграции, журналы, демо-данные). Вход: `elena.orlova@demo.example.ru` (учёная с квартилями), `dmitry.korolev@demo.example.ru` (учёный), `olga.kuznetsova@demo.example.ru` (организация); пароль `demo-password-2026` (`server/seed/seed.go`).
- `make share`: показать сайт по публичной ссылке с этого Mac (порт 8088, туннель tuna или localhost.run; Ctrl+C останавливает всё).
- `make test`: всё с порогами (около 4 минут). `make e2e`: сквозные сценарии (своя база `scibox_e2e`, журналы туда грузит `scripts/e2e-db`).
- Встроенный браузер Claude не запускает `make dev` из «Документов»: сервер и Vite запускать через Bash в фоне (`cd server && go build -o bin/scibox ./cmd/api && ./bin/scibox serve`, `cd web && npm run dev -- --strictPort`), потом `preview_start` с `url`. Остановка: `pkill -f "bin/scibox serve"; pkill -f "vite"`. Вход: `fetch('/api/auth/login', …)` через `javascript_tool`. Режим «Нанимаю»: `localStorage.setItem('scibox.role','employer')`.
- Ширина многих страниц сразу: невидимый `iframe` нужной ширины в `javascript_tool`, сравнивать `scrollWidth`; по 9–10 страниц за вызов (предел 45 с).

## Справочник журналов
- Файл: `server/internal/journals/data/scimagojr.csv.gz` (встроен в сервер). Обновление раз в год — `docs/REFERENCE.md`, раздел «Журналы и квартили». SCImago отдаёт файл только настоящему браузеру (Cloudflare), а встроенный браузер Claude файлы не сохраняет: файл скачивает пользователь («Download data» на scimagojr.com/journalrank.php) в «Загрузки».
- Условия SCImago: некоммерческое использование с подписью источника (подпись стоит под публикациями и в резюме). «Белый список» РЦНИ отложен до письма РЦНИ (D-126).
- Публикация ссылается на журнал ISSN-ом; журнал подставляется при чтении. Названия в SCImago английские (у российских журналов — переводная версия).

- Нет копирования вакансии и истории изменений; на странице организации до 50 вакансий без листания.

## Неочевидные вещи
- Порт базы **5433** (D-028). Тесты с базой: `internal/testkit`; критичные зоны сервера = пакеты в `server/coverage.conf`. Пакет `journals` использует `testkit`, поэтому `profiles` не должен импортировать `journals` (ISSN проверяет `internal/issn`).
- Ошибки 500 только через `apierr.WriteInternal` (D-119). Длинные формы: `useLeaveGuard(dirty)`, после сохранения `guard.release()`. Заголовок вкладки: `handle.title` или `usePageTitle`.
- Снимок профиля в старых откликах не содержит `quartiles`: на сайте поле необязательное.
- Тесты сайта ждут элемент до 3 секунд (`src/test/setup.ts`). Тексты только в `ru.ts`, цвета и размеры токенами, иконки из `ui/icons.tsx`; `oxlint --deny-warnings`. Не запускать `npx vitest` из корня (нужно из `web/`).
- Фоновая работа: подбор раз в 5 минут, письма из `outbox` раз в 2 секунды. Время по Москве везде (D-057, D-089, D-127).
