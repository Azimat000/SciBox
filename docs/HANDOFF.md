## Как запустить
- `make dev`: база + Mailpit, миграции и справочник журналов, сервер (127.0.0.1:8080) и сайт (http://localhost:5173). Письма: http://localhost:8025. `make db-reset`: всё заново с демо-данными. Вход: `elena.orlova@demo.example.ru`, `dmitry.korolev@demo.example.ru`, `olga.kuznetsova@demo.example.ru` (организация); пароль в `server/seed/seed.go`.
- `make share`: показать сайт по публичной ссылке с этого Mac (порт 8088, tuna или localhost.run, D-131…D-133).
- `make test`: около 5 минут. `make lint-new`: только незакоммиченные правки. `make e2e`: сквозные сценарии (база `scibox_e2e`).
- Встроенный браузер Claude не запускает `make dev` из «Документов»: сервер и Vite запускать через Bash в фоне (`cd server && go build -o bin/scibox ./cmd/api && ./bin/scibox serve`, `cd web && npm run dev -- --strictPort`), затем `preview_start` с `url`. Остановка: `pkill -f "bin/scibox serve"; pkill -f "vite"`.

## Неочевидные вещи
- Порт базы **5433** (D-028). Тесты с базой: `internal/testkit`, `internal/testdb` (адрес служебной базы можно задать `TEST_DATABASE_URL`, так делает CI). Критичные зоны сервера = строки `critical` в `server/coverage.conf`.
- `errcheck` не проверяет `fmt.Fprint*` (вывод команд в терминал, D-140). В тестах выключены `noctx` и `gosec G124`.
- Массовые правки через `perl -pi` с разделителем `|` ломают шаблоны с `\|\|` (стали «или» в регулярке и испортили 5 файлов в этой сессии; откатили). Для таких правок брать Edit или другой разделитель.
- Ошибки 500 только через `apierr.WriteInternal` (D-119). Тексты сайта только в `web/src/i18n/ru.ts`. Время по Москве везде (D-057, D-089, D-127).
- Профили не импортируют `journals` (ISSN проверяет `internal/issn`). Снимок профиля в старых откликах без `quartiles` и навыков.
- Правила полей по виду вакансии: сервер `rulesFor` (`internal/vacancies/validate.go`) и сайт `typeRules` (`web/src/features/vacancies/api.ts`) менять вместе.
- Справочник журналов SCImago обновляется раз в год вручную (`docs/REFERENCE.md`): файл скачивает пользователь.

## Известные проблемы и долги
- D-124: два почти одинаковых «Войдите…», кнопки «скоро» у входа через сервисы.
- `GET /api/landing`, `/api/recommendations/*`, `/api/scientists` без кеша и ограничения по IP (срез 19, T-07). Каталог ищет без индекса (D-098), счётчик Q1–Q2 считается подзапросом (срез 24).
- Нельзя сменить почту и удалить аккаунт (срез 20). Файлы откликов в базе без проверки на вирусы (срез 23). Почтового сервиса для настоящих людей нет (D-131).
- Сквозные тесты не входят в CI (D-140, срез 28).
- В тестах сайта есть предупреждение React о повторяющемся ключе (`offers.test.tsx`, «my offers»): тест зелёный, данные теста с одинаковыми id.
