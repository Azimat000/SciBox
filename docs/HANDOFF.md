# HANDOFF: записка следующей сессии

Обновлено: 2026-10-08. Срез 19 «Периметр HTTP» готов (`docs/slices/19-http-perimeter.md`, D-141, проверка правок `docs/slices/19-differential-review.md`). Идёт серверная очередь 18–29 (D-138), потом продуктовые 15–17.

## Где остановились
- Новый пакет `internal/httpguard` (критичная зона, 100%): сроки соединения (`NewServer`), `Perimeter` (адрес за доверенными прокси, заголовки защиты с CSP, лимит тела 1 МиБ / загрузки 64 МиБ, 5 минут на долгие передачи), `Throttle` (гость по IP, вошедший по аккаунту, 429 + Retry-After). Счётчики в таблице `rate_counters` (UNLOGGED, миграция 00015).
- Все особые адреса в одной таблице `httpapi.PerimeterRoutes`. Новый тяжёлый или публичный адрес — дописать туда; `cli.TestPerimeter` сверит её с роутером.
- `SCIBOX_ENV=production` не стартует с опасными настройками; `SCIBOX_TRUSTED_PROXIES` — кому верить X-Forwarded-For. `config` стал критичной зоной.
- Сборка сервера — `cli.newApp`; `TestPerimeter` гоняет по ней все адреса (лимит тела гостем и вошедшим, заголовки на API, сайте, файле, PDF, частота через базу, IP за прокси).
- T-04…T-09 закрыты, инварианты I-18…I-24, новые угрозы T-30 (рост `rate_counters` от IPv6, срез 27) и T-31 (прокси, не дописывающий X-Forwarded-For, срез 28).

## Как запустить
- `make dev`: база + Mailpit, миграции и справочник журналов, сервер (127.0.0.1:8080) и сайт (http://localhost:5173). Письма: http://localhost:8025. `make db-reset`: всё заново с демо-данными. Вход: `elena.orlova@demo.example.ru`, `dmitry.korolev@demo.example.ru`, `anton.vasilev@demo.example.ru` (соискатель); пароль в `server/seed/seed.go`.
- `make share`: сайт по публичной ссылке (порт 8088, tuna или localhost.run, D-131…D-133), теперь с `SCIBOX_TRUSTED_PROXIES=127.0.0.1,::1`.
- `make test`: около 5 минут. `make lint-new`: только незакоммиченные правки. `make e2e`: сквозные сценарии (база `scibox_e2e`), в срезе 19 зелёные 4/4.
- Встроенный браузер Claude не запускает `make dev` из «Документов»: сервер и Vite через Bash в фоне (`cd server && go build -o bin/scibox ./cmd/api && ./bin/scibox serve`, `cd web && npm run dev -- --strictPort`), затем `preview_start` с `url`. Проверка CSP — только на собранном сайте: `npm run build` в `web/`, сервер с `SCIBOX_HTTP_ADDR=127.0.0.1:8088 SCIBOX_WEB_DIR=…/web/dist`. Остановка: `pkill -f "bin/scibox serve"; pkill -f "vite"`.

## Неочевидные вещи
- chi называет корень поддерева по-разному: обход (`chi.Walk`) — `/api/vacancies/{id}/`, поиск адреса (`Find`) — `/api/vacancies/{id}`. Периметр сравнивает без конечной черты (`routeKey`).
- В режиме разработки страницы отдаёт Vite, CSP у них нет (горячая замена встраивает скрипт). CSP сайта видна только при `SCIBOX_WEB_DIR` (`make share`, бой).
- Ограничение частоты при сбое `rate_counters` отвечает 500 (I-09), публичный поиск тогда недоступен.
- `newApp(…, now)` принимает часы: тесты частоты стоят на замороженном времени, иначе под нагрузкой попадают на границу минуты.
- Порт базы **5433** (D-028). Тесты с базой: `internal/testkit`, `internal/testdb` (`TEST_DATABASE_URL` для CI). Критичные зоны сервера — строки `critical` в `server/coverage.conf`.
- Поддельные часы в тестах заводить с `Truncate(time.Microsecond)` (Linux в CI даёт наносекунды).
- `errcheck` не проверяет `fmt.Fprint*` и присваивание в `_` (D-140). В тестах выключены `noctx` и `gosec G124`.
- Массовые правки через `perl -pi` с разделителем `|` ломают шаблоны с `\|\|`; брать Edit или python.
- Ошибки 500 только через `apierr.WriteInternal` (D-119). Тексты сайта только в `web/src/i18n/ru.ts`. Время по Москве (D-057, D-089, D-127).
- Правила полей по виду вакансии: сервер `rulesFor` и сайт `typeRules` менять вместе.
- Скилл `golang-security` и другие `golang-*` подхватываются по путям файлов (`**/*.go`); если `Skill` его не видит, прочитать `.claude/skills/golang-security/SKILL.md` напрямую.

## Известные проблемы и долги
- D-124: два почти одинаковых «Войдите…», кнопки «скоро» у входа через сервисы.
- `/api/landing` и каталоги без кеша (срез 24); каталог ищет без индекса (D-098); `OFFSET`-пагинация (срез 24).
- Нельзя сменить почту и удалить аккаунт (срез 20). Файлы откликов в базе без проверки на вирусы (срез 23). Почтового сервиса для настоящих людей нет (D-131).
- Сквозные тесты не входят в CI (D-140, срез 28). Поведение tuna/localhost.run с X-Forwarded-For не проверено на живом туннеле (T-31).
- В тестах сайта предупреждение React о повторяющемся ключе (`offers.test.tsx`), тест зелёный.
