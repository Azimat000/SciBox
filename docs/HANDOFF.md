## Неочевидные вещи
- **Справочник навыков:** профиль ссылается на навык строкой, не ключом. Ключ сравнения один на сервере (`skills.Key`) и на сайте (`skillKey` в `ui/skills.ts`): правка одного требует правки второго. Тесты пакета `skills` лежат во внешнем пакете `skills_test` (testkit тянет профили, иначе круг импортов); закрытые имена открывает `export_test.go`. В тестах профилей справочник свой, с редкими названиями, и убирается после теста (база общая на пакет).
- **Подсказка «не нашли»** показывается, когда справочник ответил на текущий запрос (`debounced === query && !isFetching`); Enter до ответа добавляет написанное, сервер приведёт к каноническому при сохранении.
- **Новое поле профиля (идентификатор):** столбец с `DEFAULT` (миграции после 00024 только добавляют, D-186), `UpdateProfileCore` в `profiles.sql` + `go tool sqlc generate`, `CoreInput`, `coreFields`, `validateCore`, `Identifiers`, `build`, `SaveCore`, `idFacts` в резюме; на сайте `api.ts`, `ProfileEditPage`, `ProfileView`, `ru.ts`, `test/profile.ts`. Снимок отклика, выгрузка данных и стирание получают поле сами; безымянная карточка нет (`blindView`).
- **Тест миграций** (`migrate_test.go`) перечисляет миграции по именам: новая миграция добавляется в три места (первый `up`, `down` в начале спуска, `up` перед `reset`); индексы в миграции только `IF NOT EXISTS` (`safety_test.go`).
- **Выгрузка откликов:** данные берутся из снимка отклика, не профиля (D-079); новая колонка идёт через `ExportRow`, `exportHeader`, `WriteCSV`, каждая ячейка с текстом людей через `cell` (T-87).
- **Как смотреть профиль в новом коде:** не сравнивать `visibility` строкой; собрать `privacy.Viewer` (`ListUserOrgIDs`, `ProfileOrgRelations`), спросить `CanView`/`Detail`/`CanSeeContacts`; в списках организации имя решает `privacy.ShowsName`.
- **iCloud Drive:** Mac выгружает файлы проекта (флаг `dataless`), тесты сайта, `docker build` и `git` зависают. Зависимости сайта в `web/node_modules.nosync`. Лечится: `find web server deploy config -type f -flags +dataless -exec cat {} +`. Свободного места держать не меньше ~12 ГБ (сейчас около 7 ГБ: осторожно с `make load-data`, `prod-up`).
- **Лимиты:** новый счётчик «не больше N» в транзакции начинать с `q.LockRateKey(ctx, kind+":"+key)` (I-80). Тексты человека проверяет периметр и `DecodeJSON` (`textsafe`). Новый адрес API: строка в `PerimeterRoutes` и в таблице прав `access_cases_test.go`.
- Каждая сборка Docker даёт новый номер образа базы (`deploy/db-image-tag`). `go build`/`go test` без git-индекса: `GOFLAGS=-buildvcs=false`. Порт базы 5433. Ошибки 500 только через `apierr.WriteInternal`. Тексты сайта только в `web/src/i18n/ru.ts`. `npx prettier` в `web/` не запускать. Запуск dev-сервера через `preview_start` падает («getcwd»): `make dev` или `scripts/dev.sh` из терминала. В zsh `grep --include=*.go` нужно брать в кавычки.
- Mac: Docker (Colima) сейчас 5 ядер; вернуть: `colima stop && colima start --cpu 2 --memory 4`.
