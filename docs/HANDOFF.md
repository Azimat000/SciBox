## Неочевидные вещи
- **Тест сборки** `web/src/features/chat/build.test.ts` собирает сайт Vite дважды (боевой режим без подставного сервера, режим разработки с ним). Vitest ставит `NODE_ENV=test`, а по нему Vite решает `import.meta.env.DEV`: тест выставляет `NODE_ENV` сам.
- **Сверка контракта:** форма собирается из всех примеров файла; поле, которого нет хоть в одном примере объекта, становится необязательным; объект-словарь (`error.fields`) объявляется в `maps`, разные виды (системные строки, события потока) в `variants`. Новый вид системной строки: перечень в `enums.json`, пример в `messages.json`, подпись в `t.chat.events`.
- **Поле `chat` у откликов и приглашений** дописывает `mock/decorate.ts` (одна переписка на учёного и вакансию по `vacancy.id`; у организации на отклик или приглашение). Тип поля необязательный (`chat?: ChatRef | null`): без него кнопок нет.
- **Сторона и режим:** список просят по `side` из режима «Ищу работу / Нанимаю»; число в шапке общее; на странице подсказка о непрочитанном в другом режиме.
- **Шапка:** места впритык (D-218: соискатель 41 px запаса при 1440). Новый значок или пункт меню потребует заново сжать или убрать имя в кнопке пользователя.
- **Зона покрытия чата** в `vite.config.ts` — `'src/features/chat/*.{ts,tsx}'` (только файлы папки, `mock/` вне зоны).
- Прежние: справочник навыков (`skills.Key` ↔ `skillKey`), новое поле профиля проходит по цепочке из `profiles.sql`…`test/profile.ts`, `migrate_test.go` перечисляет миграции, выгрузка откликов из снимка (D-079), профиль смотреть через `privacy.Viewer`, лимиты через `q.LockRateKey`, новый адрес API = строка в `PerimeterRoutes` и `access_cases_test.go`.
- **iCloud Drive:** файлы проекта выгружаются (`dataless`), тесты и git зависают; лечится `find web server deploy config -type f -flags +dataless -exec cat {} +`. Зависимости сайта в `web/node_modules.nosync`. Свободно около 8 ГБ: осторожно с `make load-data`, `prod-up`.
- `preview_start` падает («getcwd»): `make dev` из терминала; снимки удобнее делать Playwright из `e2e/node_modules`. `npx prettier` в `web/` не запускать. Тексты только в `web/src/i18n/ru.ts`. Порт базы 5433.
