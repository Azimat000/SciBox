## Неочевидные вещи
- **iCloud Drive:** папка проекта в «Документах»; Mac выгружает файлы (флаг `dataless`), тесты сайта, `docker build` и `git` зависают. Зависимости сайта теперь в `web/node_modules.nosync` (ссылка `web/node_modules`, iCloud такие папки не трогает; в `.gitignore`). Остальное лечится: `find web server deploy config -type f -flags +dataless -exec cat {} +`. Свободного места держать не меньше ~12 ГБ (на конец среза было ~10 ГБ).
- **Помощники тестов** ставят `Binding: "test-registration-browser"` в `Meta` (`auth.env.meta()`, `testkit.Meta()`, `world.meta()` в `orgs`, `profiles`, `vacancies`): регистрация и подтверждение в тестах идут «из одного браузера». Новый помощник с `auth.Meta{}` без этого поля получит `ConfirmedElsewhereError` при подтверждении.
- **Лимиты:** новый счётчик «не больше N» в транзакции начинать с `q.LockRateKey(ctx, kind+":"+key)`, иначе гонка (I-80). Вне транзакции: `auth.reserve` или `profiles.spendKind`.
- **Текст человека:** строки из тела, пути и параметров проверяет периметр и `DecodeJSON` (`textsafe`); новые разборщики добавлять с фаззингом по образцу `*/fuzz_test.go`.
- Каждая сборка Docker даёт новый номер образа: имя образа базы содержит отпечаток (`deploy/db-image-tag`). Правка `deploy/postgres/**` перезапустит базу при выкладке.
- Миграции после 00024 только добавляют (D-186); `application_files.legacy_data` ещё не удалён.
- `go build`/`go test` без git-индекса: `GOFLAGS=-buildvcs=false`. Порт базы 5433. Ошибки 500 только через `apierr.WriteInternal`. Тексты сайта только в `web/src/i18n/ru.ts`. `npx prettier` в `web/` не запускать.
- Mac: Docker (Colima) сейчас 5 ядер; вернуть: `colima stop && colima start --cpu 2 --memory 4`.
