## Неочевидные вещи
- **Миграции после 00024 только добавляют** (D-186, `migrate/safety_test.go`): новый столбец с `DEFAULT`; `ALTER … ADD CONSTRAINT`, `DROP …`, `SET NOT NULL` без метки `scibox:contract` тест отвергает. `vacancy_view` пересоздаётся `CREATE OR REPLACE`: старые столбцы на местах, новые в конец (в 00028 список выписан явно, звёздочка больше не используется).
- **Новое поле вакансии:** `Input` и `fields` (`validate.go`), `CreateVacancy`/`UpdateVacancy` в `vacancies.sql` и оба вызова в `service.go` (Create и Update), `inputOf`, `body` в `http.go`, `cardFrom`/`Get`, форма и `VacancyEditPage.valuesOf`, `test/vacancies.ts`. Пропущенный вызов даёт тихую потерю значения: тест круга записи и чтения обязателен.
- **Новое условие поиска:** `SearchParams`, `ParseSearchQuery`, `Encode`, `HasConditions`, SQL `SearchVacancies`, `web/features/search/params.ts` (+ чипы, `labels.ts`, панель). В ключ кеша оно попадает само (`cacheKey` кодирует `SearchParams` целиком).
- **Выгрузка:** данные берутся из снимка отклика, а не профиля (D-079); новая колонка файла идёт через `ExportRow`, `exportHeader` и `WriteCSV`, каждая ячейка с текстом людей через `cell` (формулы, T-87).
- **Как смотреть профиль в новом коде:** никогда не сравнивать `visibility` строкой. Собрать `privacy.Viewer` (`ListUserOrgIDs`, `ProfileOrgRelations`), спросить `CanView`/`Detail`/`CanSeeContacts`; в списках организации имя решает `privacy.ShowsName`. Безымянная карточка собирается только в `profiles.blindView` списком разрешённого.
- **iCloud Drive:** Mac выгружает файлы проекта (флаг `dataless`), тесты сайта, `docker build` и `git` зависают. Зависимости сайта в `web/node_modules.nosync`. Лечится: `find web server deploy config -type f -flags +dataless -exec cat {} +`. Свободного места держать не меньше ~12 ГБ (сейчас около 8 ГБ).
- **Помощники тестов** ставят `Binding: "test-registration-browser"` в `Meta`; новый помощник с `auth.Meta{}` без этого получит `ConfirmedElsewhereError`. Тест, меняющий `exportLimit` (`applications`), возвращает его через `defer`.
- **Лимиты:** новый счётчик «не больше N» в транзакции начинать с `q.LockRateKey(ctx, kind+":"+key)` (I-80). Тексты человека проверяет периметр и `DecodeJSON` (`textsafe`).
- Каждая сборка Docker даёт новый номер образа базы (`deploy/db-image-tag`). `go build`/`go test` без git-индекса: `GOFLAGS=-buildvcs=false`. Порт базы 5433. Ошибки 500 только через `apierr.WriteInternal`. Тексты сайта только в `web/src/i18n/ru.ts`. `npx prettier` в `web/` не запускать. Запуск dev-сервера через `preview_start` падает («getcwd»): `make dev` из терминала.
- Mac: Docker (Colima) сейчас 5 ядер; вернуть: `colima stop && colima start --cpu 2 --memory 4`.
