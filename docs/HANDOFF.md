## Как запустить
- `make dev` (сайт http://localhost:5173, сервер 8080). Встроенный предпросмотр приложения не может запустить его из «Документов» (macOS не даёт доступа, `getcwd`), поэтому запускать во вкладке терминала. Демо-вход `elena.orlova@demo.example.ru` (организация), `dmitry.korolev@demo.example.ru` (учёный), пароль в `server/seed/seed.go`.
- `make test` (≈20 минут; при свободной памяти быстрее), `make lint-new`, `make vulncheck`, `make e2e`; `npm run lint`, `npm run typecheck` в `web/`.
- Если тесты падают на «ClamAV недоступен»: `docker restart scibox-clamav-1` и подождать «healthy». Если `make dev` пишет «clamav is unhealthy» при работающей репетиции: остановить репетицию (`make prod-down`), память Docker общая.
- Репетиция боевого стенда: `make prod-up`, `make prod-e2e`; перед повторным прогоном очистить счётчики частоты: `docker exec scibox-prod-postgres-1 psql -U scibox -d scibox -c "truncate rate_counters; delete from rate_events"` (иначе регистрация упирается в 429); `make prod-down`.

## Неочевидные вещи
- **Раздача чата**: Caddy раскладывает потоки по копиям (`least_conn`); копия без работающей раздачи молчала бы, поэтому `admit` отказывает, пока `waiting`.
- **Тесты чата**: общий тестовый мир ставит огромные пределы; тесты пределов вызывают `w.svc.WithLimits(DefaultLimits())`.
- **Порядок замков**: отклик или приглашение, строка переписки, счётчик человека, счётчик организации.
- **`make test` запускает полный `make lint`**; в тестах знаки смены направления писать как `\u202e` в строке, не самим знаком.
- На macOS `sed -i` требует `''`; `timeout` нет. На iCloud файлы проекта выгружаются (`dataless`): `find web server deploy config -type f -flags +dataless -exec cat {} +`; зависимости сайта в `web/node_modules.nosync`; порт базы 5433; `npx prettier` в `web/` не запускать; тексты только в `web/src/i18n/ru.ts`.
- Прежние неочевидные вещи среза 40 (замки счётчиков, «5 подряд», `client_id`) в `docs/CHAT.md` и `docs/slices/40-chat-security.md`.
