# HANDOFF: записка следующей сессии

Обновлено: 2026-10-11. Срез 15 «Анонимный режим и «скрыть от моей организации»» готов (`docs/slices/15-anonymous-mode.md`, D-199…D-206, метка `slice-15`). `ТЕКУЩИЙ: 16` (условия для учёного и выгрузка откликов), затем 17 и 30.

## Где остановились
- **Новое в поведении:** четвёртый режим «Анонимно» (организации видят научный облик без имени, места работы, города, идентификаторов, названий работ, контактов и резюме); имя открывается организации, когда человек откликнулся на её вакансию или ответил «Интересно» (`profile_reveals`); «Скрыть от организаций» (до 50, в любом режиме, `profile_hidden_orgs`). Решает одна функция `privacy.Visibility.Disclose` → закрыт / анонимная карточка / полностью.
- **Что это значит для срезов 16 и 17:** выгрузка откликов (16) берёт имя из отклика (человек откликнулся сам, имя уже открыто) и ничего не меняет в приватности. «Подходящие учёные» (17) обязаны идти через `Disclose`/`ViewerFlags` и SQL-условия каталога: аноним показывается анонимно (`masked`, `label`), скрытый от организации не показывается вовсе, слова и регион анонима не находят (I-97…I-102, D-203). Не обходить их новым запросом.
- **Ждёт пользователя вне кода:** хостинг и `docs/DEPLOY.md`; модерация организаций (срез 30, D-197: пользователь сам опишет); юрист: сроки хранения откликов (T-37), политика `/privacy` (в ней про режим «Анонимно» ничего нет, её текст ещё черновик, версия `2026-10-draft`).

## Неочевидные вещи
- **iCloud Drive:** папка проекта в «Документах»; Mac выгружает файлы (флаг `dataless`), тесты сайта, `docker build` и `git` зависают. Зависимости сайта теперь в `web/node_modules.nosync` (ссылка `web/node_modules`, iCloud такие папки не трогает; в `.gitignore`). Остальное лечится: `find web server deploy config -type f -flags +dataless -exec cat {} +`. Свободного места держать не меньше ~12 ГБ (на конец среза было ~10 ГБ).
- **Помощники тестов** ставят `Binding: "test-registration-browser"` в `Meta` (`auth.env.meta()`, `testkit.Meta()`, `world.meta()` в `orgs`, `profiles`, `vacancies`): регистрация и подтверждение в тестах идут «из одного браузера». Новый помощник с `auth.Meta{}` без этого поля получит `ConfirmedElsewhereError` при подтверждении.
- **Лимиты:** новый счётчик «не больше N» в транзакции начинать с `q.LockRateKey(ctx, kind+":"+key)`, иначе гонка (I-80). Вне транзакции: `auth.reserve` или `profiles.spendKind`.
- **Текст человека:** строки из тела, пути и параметров проверяет периметр и `DecodeJSON` (`textsafe`); новые разборщики добавлять с фаззингом по образцу `*/fuzz_test.go`.
- Каждая сборка Docker даёт новый номер образа: имя образа базы содержит отпечаток (`deploy/db-image-tag`). Правка `deploy/postgres/**` перезапустит базу при выкладке.
- Миграции после 00024 только добавляют (D-186); `application_files.legacy_data` ещё не удалён.
- `go build`/`go test` без git-индекса: `GOFLAGS=-buildvcs=false`. Порт базы 5433. Ошибки 500 только через `apierr.WriteInternal`. Тексты сайта только в `web/src/i18n/ru.ts`. `npx prettier` в `web/` не запускать.
- Mac: Docker (Colima) сейчас 5 ядер; вернуть: `colima stop && colima start --cpu 2 --memory 4`.
- **Срез 15:** `privacy.Viewer` теперь несёт `Blocked` и `Revealed`; в тестах «скрыть» и «раскрыть» делают `profiles.HideFrom` и прямая вставка в `profile_reveals` (помощник `reveal` в `profiles/anonymous_test.go`). Миграция `00027` помечена `-- scibox:contract` (меняет CHECK режима; безопасна одним выпуском, D-205). `golangci-lint` из `~/go/bin` (2.12.2): системный 2.5 не читает `go 1.26`.
- **Облачная сессия без Docker:** тесты с базой идут на PostgreSQL, запущенном напрямую на 5433 (`initdb`, роль `scibox`); S3 и ClamAV нет, поэтому `blobstore`, `antivirus`, часть `cli` (serve, наблюдаемость, сидирование) здесь не проходят, это среда, а не код.
