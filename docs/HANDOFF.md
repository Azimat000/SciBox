# HANDOFF: записка следующей сессии

Обновлено: 2026-10-10. Срез 25 «Несколько копий сервера и фоновые задачи» готов (`docs/slices/25-background-and-copies.md`, D-167…D-171, разбор правок `docs/slices/25-differential-review.md`). Идёт серверная очередь 18–29 (D-138), потом продуктовые 15–17. `ТЕКУЩИЙ: 26` (наблюдаемость).

## Где остановились
- **Процессы.** `scibox serve` (HTTP; с `SCIBOX_BACKGROUND=on`, по умолчанию, ещё и задачи) и `scibox worker` (только задачи). Копий любое число: общее расписание в таблице `job_runs`, письма и файлы берутся в аренду. Сборка: `internal/cli` (`services` → `router` и `jobs`), список задач `internal/cli/jobs.go` (11 задач, таблица в `docs/ARCHITECTURE.md`).
- **`internal/jobs`** (критичная зона): задачи «на весь кластер» (раз в срок на все копии) и «в каждой копии»; нарастающая пауза после сбоев, перехват паник, мягкая остановка (`jobs.Draining(ctx)` в задачах, `SCIBOX_SHUTDOWN_TIMEOUT`), сверка часов с базой (копия с часами не в порядке ничего не исполняет). `Runner.Snapshot()` отдаёт состояние задач.
- **`internal/resilience`**: `Breaker` и `Limiter` под `Gate`. Crossref: 1 одновременный запрос на копию (`SCIBOX_CROSSREF_MAX_CONCURRENT`), 5 сбоев подряд или 429 открывают предохранитель. Почта: `mail.Error` с видом сбоя; сбой службы не тратит попытки письма, постоянный отказ сразу в недоставленные, предохранитель на 5 сбоев; остановка возвращает неотправленные письма.
- **Тесты нескольких копий:** `cli.TestSeveralCopiesNeverSendTwice` (два сервера и два воркера, 1000 событий, воркера останавливают посреди работы) и `TestDirectCallsFromSeveralCopiesNeverDuplicate`. Идут под `-race` в `make test` (около 40 секунд вместе).

## Как запустить
- `make dev`: база, почта, хранилище файлов (8333), ClamAV (3310), миграции, **сервер без фоновых задач, воркер** и сайт (http://localhost:5173). `make worker` — только воркер. `make share` запускает то же через туннель. Вход: `elena.orlova@demo.example.ru` (владелец), `dmitry.korolev@demo.example.ru` (соискатель); пароль в `server/seed/seed.go`.
- `make test`: около 12 минут (линтер, vulncheck, сервер с порогами, сайт). `make e2e` (6 из 6 зелёные после среза 25; сервер и воркер запускает `e2e/playwright.config.ts`, журналы `e2e/server.log`, `e2e/worker.log`).
- `make load-data` / `make load-check` (срез 24): базы `scibox_load` на этом Mac нет (удалена, ≈ 7 ГБ); перед пересозданием освободить ≥ 10 ГБ.
- Встроенный браузер Claude не запускает `make dev` из «Документов»: `cd server && go build -o bin/scibox ./cmd/api`, затем `SCIBOX_BACKGROUND=off ./bin/scibox serve`, `./bin/scibox worker` и `cd web && npm run dev -- --strictPort`, потом `preview_start` с `url`.

## Неочевидные вещи
- **Новая фоновая задача:** добавить в `cli/jobs.go` (имя `раздел.действие`, вид, срок); сам проход не знает про расписание. Задача должна проверять `jobs.Draining(ctx)` между порциями и быть повторяемой: после падения копии её возьмёт другая.
- `ClaimOutbox` возвращает строки в порядке, который выбрала база, а не по очереди: тесты не должны на порядок внутри пачки рассчитывать.
- Тесты `jobs` лежат во внешнем пакете `jobs_test`: `testkit` тянет `notifications`, а тот импортирует `jobs` (иначе цикл импортов). Тест `FaultDB` считает обращения к базе по порядку: сверка часов исполнителя — первое.
- Предохранители у каждой копии свои (T-50). Письма уйдут дважды, если процесс упал между «принято» и записью (T-48, принято).
- Соединения: сервер до 20, воркер до 10 (`cli.workerMaxConns`), в базе 100: две копии сервера и воркер = 50.
- **Папка проекта лежит в iCloud («Документы») и при нехватке диска macOS выгружает файлы в облако** (в срезе 24 это случилось с `.git/index` и `node_modules`; признак: `Operation timed out`, `ls -lO` показывает `dataless`). Лечение: `cat файл > /dev/null`; для индекса `GIT_INDEX_FILE=<другой файл> git …`; держать ≥ 10 ГБ свободно (Colima: `colima ssh -- sudo fstrim -av` после удаления баз). Вывод проекта из синхронизации обсуждается. На 2026-10-10 свободно 16 ГБ.
- `go build` и `go test` без git-индекса требуют `GOFLAGS=-buildvcs=false`. Порт базы **5433**. Ошибки 500 только через `apierr.WriteInternal`. Тексты сайта только в `web/src/i18n/ru.ts`. `npx prettier` в `web/` не запускать.
- zsh: переменная с пробелами не раскрывается в команду; для `psql` в `docker compose exec` писать функцию.
