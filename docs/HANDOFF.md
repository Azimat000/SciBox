## Неочевидные вещи
- **Шаблоны подставного сервера в одной корзине** на любые номера организаций (`MOCK_ORG_ID`): у шапки переписки номер демо-организации, у страницы правки настоящий; настоящий сервер различает их по номеру.
- **Действия в шапке:** у соискателя всё в «Ещё» (`ChatActions.tsx`), у организации «В архив» кнопкой. Список «Ещё» привязан к `.chat-window-top`.
- **Фокус при открытии** окна на заголовок только если список скрыт (телефон) или фокуса нет (`listHidden` в `ChatPane.tsx`).
- **`useArchive.ts` отдельным файлом:** правило oxlint запрещает экспортировать хуки из файла компонентов.
- Прежние: состояние приглашения считается по строкам ленты (`events.ts`); копия состояния в `useConversation.ts` обновляется синхронно; колонка панели `minmax(0, 1fr)`; окно просмотра приложения у фонового окна не шлёт событий прокрутки; сборка `build.test.ts` и сверка `contract.test.ts`; зона покрытия `'src/features/chat/*.{ts,tsx}'` (без `mock/`).
- **iCloud Drive:** файлы проекта выгружаются (`dataless`), тесты и git зависают; лечится `find web server deploy config -type f -flags +dataless -exec cat {} +`. Зависимости сайта в `web/node_modules.nosync`. Свободно около 8 ГБ: осторожно с `make load-data`, `prod-up`.
- `preview_start` падает («getcwd»): `make dev` из терминала. `npx prettier` в `web/` не запускать. Тексты только в `web/src/i18n/ru.ts`. Порт базы 5433.
