## Неочевидные вещи
- **Тесты чата**: общий тестовый мир (`newWorld`) ставит огромные пределы, чтобы обычные тесты могли писать много подряд; тесты пределов вызывают `w.svc.WithLimits(DefaultLimits())` или свои цифры. Новый тест, который пишет больше пяти текстов от одной стороны, пределами не мешает.
- **Строки о событиях и «подряд без ответа»**: ответом служит только текст другой стороны; удалённые тексты считаются. Переписка из теста (`chatOf`) создаётся без строки «отклик отправлен», поэтому тексты в ней идут с номера 1.
- **Порядок замков**: отклик или приглашение, строка переписки, затем счётчик человека, затем счётчик организации. Новый код с замками соблюдает его (`checkSendLimits`).
- **`make test` запускает полный `make lint`**, а не `lint-new`: замечания в тестах (знаки смены направления в строках: писать `\u202e` в строке, не самим знаком; `os.ReadFile` по переменной: `//nolint:gosec` с причиной) всплывают только там.
- Прежние: поток без `SetWriteDeadline` рвётся по `WriteTimeout`; событие собирается для каждого получателя отдельно (`framesFor`); `chat.state` и `unread.count` без номера; состояние приглашения считается по строкам ленты (`events.ts`, D-223); на iCloud файлы проекта выгружаются (`dataless`), лечится `find web server deploy config -type f -flags +dataless -exec cat {} +`; зависимости сайта в `web/node_modules.nosync`; порт базы 5433; `make dev` из терминала; `npx prettier` в `web/` не запускать; тексты только в `web/src/i18n/ru.ts`.
