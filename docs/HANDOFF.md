- D-124 (выше). Вход: два почти одинаковых сообщения «Войдите…» подряд; четыре кнопки «скоро» занимают много места. Гость видит в меню «Избранное» и «Мои отклики» (ведут на вход).
- `GET /api/landing`, `/api/recommendations/*`, `/api/scientists` без кеша и без ограничения по IP. Каталог ищет без индекса (D-098); стеммер не сводит «Седов» и «Седова».
- Одинаковые сохранённые поиски не запрещены; нет счётчика «новых по поиску»; календарь сроков без сетки месяца и `.ics`. Подбор смотрит до 500 новейших вакансий (D-109). Рассылки в одном процессе с сервером.
- Решение по отклику окончательное (D-088), истории статусов нет; отправленный отклик нельзя править. Письма об откликах и приглашениях отключить нельзя (D-106).
- Файлы откликов в базе (D-080), без проверки на вирусы. Почта по SMTP без шифрования (D-020). Нельзя сменить почту, удалить аккаунт и организацию кнопкой.
- Профиль: нет подсказки о заполненности, фото, импорта из ORCID. `/privacy` черновик (`2026-10-draft`). Тёмной темы нет (по решению). `mail` покрыт на 90,9%.
- Нет копирования вакансии и истории изменений; на странице организации до 50 вакансий без листания.

## Неочевидные вещи
- Порт базы **5433** (D-028). Тесты с базой: `internal/testkit`; в `matching` и `landing` каждый тест сначала уводит старые вакансии в архив. Критичные зоны сервера = имена пакетов в `server/coverage.conf`.
- Ошибки 500 в разделах сервера отвечаются только через `apierr.WriteInternal(w, r, logger, "раздел", err)` (D-119); новые обработчики делать так же.
- Длинные формы: `useLeaveGuard(dirty)` из `ui/`, перед переходом после сохранения вызвать `guard.release()` (иначе форма спросит «Уйти?»). `useForm` отдаёт `dirty`.
- Заголовок вкладки: простая страница пишет `handle: { title: t.pageTitles.… }` в `routes.tsx`, страница с данными вызывает `usePageTitle(...)` из `app/pageTitle.ts`.
- Сквозные тесты: искать элементы по ролям и подписям; у полей в подписи есть « · обязательно», поэтому `getByLabel(/^Должность/)`; переключатели сохраняются после ответа сервера (`click`, затем `toBeChecked`). Регистрация ограничена по частоте: при ручных прогонах с `E2E_REUSE=1` пересоздавать базу `./scripts/e2e-db`.
- `break-ui`: `e2e/fixtures/worst-case.sql` заливается в `scibox_e2e` после `./scripts/e2e-db`.
- Фоновая работа: `matching.Service.Run` раз в 5 минут (`SendDigests`, `SendReminders`), письма из `outbox` раз в 2 секунды. Время по Москве везде (D-057, D-089).
- Фронтенд: тексты только в `src/i18n/ru.ts`, цвета и размеры только токенами, иконки только из `ui/icons.tsx`; `oxlint --deny-warnings` строгий. Тесты: `stubApi` (`web/src/test/api.ts`), не запускать `npx vitest` из корня (нужно из `web/`).
