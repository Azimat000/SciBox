## Как запустить
- `make dev`: база + Mailpit, миграции, сервер (127.0.0.1:8080) и сайт (http://localhost:5173). Письма: http://localhost:8025. Остановка: Ctrl+C.
- `make db-reset`: пересоздать базу и демо-данные (30 организаций, ~216 вакансий, 17 людей, 14 профилей, 14 откликов, 6 приглашений на вакансии, 18 избранных у шести учёных, 7 сохранённых поисков). Вход: `ksenia.lebedeva@demo.example.ru` (геология), `dmitry.korolev@demo.example.ru` (биология), `alina.guseva@…`, `natalia.zhukova@…`, `artem.morozov@…`, `igor.tarasov@…`; организации: `olga.kuznetsova@…`; все `@demo.example.ru`, один пароль в `server/seed/seed.go`.
- `make test`: всё с проверкой покрытия (около 4 минут; сам поднимает Docker-контейнеры).
- Встроенный браузер Claude не запускает `make dev` из «Документов»: сервер и Vite запускать через Bash в фоне (`cd server && go build -o bin/scibox ./cmd/api && ./bin/scibox serve`, `cd web && npm run dev -- --strictPort`), затем `preview_start` с `url`. Остановка: `pkill -f "bin/scibox serve"; pkill -f "vite --strictPort"`. Вход делать запросом `fetch('/api/auth/login', …)` через `javascript_tool`; выйти: `POST /api/auth/logout`. Режим «Нанимаю»: `localStorage.setItem('scibox.role','employer')`, обратно `'seeker'`. Для телефона `resize_window` с пресетом `mobile`, потом вернуть `desktop`. Снимок экрана в панели обрезает страницу до 800 px: при 1440 брать `computer zoom` с областью всей страницы. Не запускать `npx vitest` из корня проекта (нужно из `web/`).

## Известные проблемы и долги
- Полный `/impeccable critique`, `/impeccable audit`, `break-ui` и `web-design-guidelines` не делались для срезов 3–12 (только детектор, замеры и браузер). Всё это срез 13.
- `GET /api/landing` без кеша и без ограничения по IP; считает на каждый заход. Сумма вакансий по областям может быть больше общего числа (вакансия в нескольких областях считается в каждой).
- Главная не показывает ничего про организации-партнёры и не должна: логотипов и отзывов нет (`PRODUCT.md`). Заголовок вкладки браузера везде «SciBox».
- Одинаковые сохранённые поиски не запрещены (предел 20). Нет счётчика «новых по поиску». Календарь сроков без сетки месяца и без `.ics`.
- Подбор смотрит до 500 новейших вакансий нужных групп (D-109). Рассылки и напоминания работают в одном процессе сервера.
- Каталог ищет на лету без индекса (D-098). Русский стеммер не сводит «Седов» и «Седова».
- Приглашение на вакансию: нет напоминаний, нет фильтра по вакансии на `/sent-offers`. Лимит 20 приглашений в сутки (D-099).
- Решение по отклику окончательное (D-088); истории статусов нет; нет поиска по имени кандидата. Отправленный отклик нельзя править.
- Письма об откликах, приглашениях и решениях отключить нельзя (D-106).
- Публичные `/api/recommendations/*` и каталог `/api/scientists` не ограничены по IP. Файлы откликов лежат в базе (D-080), на вирусы не сканируются.
- Профиль: нет подсказки о заполненности, фото, импорта из ORCID. «Виден организациям» = любой сотрудник любой организации (D-072).
- Почта по SMTP без шифрования (локально, D-020). Нельзя сменить почту, удалить аккаунт и организацию кнопкой.
- Текст `/privacy` черновик (нужен юрист; версия `2026-10-draft`). Тёмной темы нет. `mail` покрыт на 90,9%.
- Нет копирования вакансии и истории изменений; на странице организации до 50 вакансий без листания.

## Неочевидные вещи
- Порт базы **5433** (D-028). Тесты с базой: `internal/testkit`; в пакетах `applications`, `offers`, `matching` помощники в `helpers_test.go`. В `matching` и `landing` каждый тест начинает с того, что старые вакансии уходят в архив (числа и фоновые проходы считают всё, что есть в базе). Критичные зоны сервера = имена пакетов в `server/coverage.conf`.
- Главная: сетка на самой `.landing` (hero слева, `.hero-browse` справа в первой строке; остальное во всю ширину); порядок в разметке hero → свежие → оглавление → дорожки → наука, чтобы на узких экранах оглавление шло после вакансий. Дорожки на `subgrid` (4 общие строки). Свежие вакансии: `GET /api/vacancies?limit=6`, ключ запроса начинается с `vacancies`.
- Фоновая работа: `matching.Service.Run` (раз в 5 минут) вызывает `SendDigests` и `SendReminders`; письма идут в `outbox`, отправитель берёт их раз в 2 секунды.
- Время по Москве везде (D-057, D-089); в SQL `AT TIME ZONE 'Europe/Moscow'`.
- Уведомления: `notifications.Service.Emit(ctx, q, …)` в транзакции события. Права: `access` через `orgs.ActorOf` и `orgs.ScopeOf(perm)`; приватность профиля решает `privacy`.
- Тесты фронтенда: `stubApi` (`web/src/test/api.ts`; `signedInAs`), фикстуры в `web/src/test/` (`landing.ts`, `matching.ts`, `offers.ts`, `applications.ts`, `vacancies.ts`); запрос с `*` на конце в таблице `stubApi` отвечает на любой адрес с таким началом. Тесты, считающие ссылки «Организации» и т. п., должны искать внутри нужной области (шапка тоже содержит ссылки).
- Фронтенд: `VacancyCard` принимает `action`, `footer`, `showDeadline`; формы на `useForm`; `oxlint --deny-warnings` строгий (нельзя `new Date()` в отрисовке).
- `vacancy_view`: добавили колонку в `vacancies` — пересоздать представление в новой миграции и `go tool sqlc generate`. В sqlc `ORDER BY` по выражению над сгруппированным столбцом нужно делать через подзапрос.
- Название продукта: `config/product.json` (D-029). Цвета и размеры только через токены; тексты только в `src/i18n/ru.ts`. Без эмодзи и юникод-значков вместо иконок: только `ui/icons.tsx`.
