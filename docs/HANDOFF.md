## Неочевидные вещи
- **Состояние приглашения** считается по следующим строкам ленты (`events.ts`), не по снимку в строке «создано»; новый вид строки: перечень в `enums.json`, пример в `messages.json`, подпись в `t.chat.events` и `t.chat.line`, ветка в `SystemLine.tsx`.
- **Копия состояния ленты** (`useConversation.ts`): `stateRef` обновляется в обёртке `dispatch` синхронно, не в эффекте; иначе дочитывание сразу после загрузки видело пустую ленту и грузило всю историю.
- **Колонка панели** `.chats-pane` держит `minmax(0, 1fr)`: без этого длинная подпись автора в ленте растягивала окно за экран.
- **Подставной сервер ведёт строки** на действия откликов и приглашений (`mock/actions.ts`): демо-записи сам, настоящие через `mirror` после успеха настоящего ответа. Подмена `fetch` стоит и на адресах `/api/applications/…/answer` и т. п.
- **Окно просмотра** в приложении у фонового окна не шлёт события прокрутки: проверять прокрутку колёсиком (`computer scroll`) после снимка экрана.
- **Тест сборки** `build.test.ts` и сверка контракта `contract.test.ts`: без изменений (см. срез 34). Зона покрытия чата в `vite.config.ts` — `'src/features/chat/*.{ts,tsx}'` (только файлы папки, `mock/` вне зоны).
- Прежние: справочник навыков (`skills.Key` ↔ `skillKey`), новое поле профиля по цепочке `profiles.sql`…`test/profile.ts`, `migrate_test.go` перечисляет миграции, выгрузка откликов из снимка (D-079), профиль через `privacy.Viewer`, лимиты через `q.LockRateKey`, новый адрес API = строка в `PerimeterRoutes` и `access_cases_test.go`.
- **iCloud Drive:** файлы проекта выгружаются (`dataless`), тесты и git зависают; лечится `find web server deploy config -type f -flags +dataless -exec cat {} +`. Зависимости сайта в `web/node_modules.nosync`. Свободно около 8 ГБ: осторожно с `make load-data`, `prod-up`.
- `preview_start` падает («getcwd»): `make dev` из терминала; снимки Playwright из `e2e/node_modules`. `npx prettier` в `web/` не запускать. Тексты только в `web/src/i18n/ru.ts`. Порт базы 5433.
