# Предметная область: термины

Пополняется по ходу срезов. Код использует английские идентификаторы из колонки «В коде».

| Термин | Что значит | В коде |
|---|---|---|
| Соискатель | Человек, который ищет позицию; у него профиль учёного | `seeker`, `profile` |
| Организация | Вуз, НИИ, институт РАН, научный центр, компания с R&D, технопарк | `organization` |
| Подразделение | Кафедра, лаборатория, отдел, ЦКП внутри организации; есть руководитель и темы | `unit` |
| Научный руководитель | Руководитель подразделения, публикует позиции в свою лабораторию | `unit_head` |
| Вид вакансии | Научный работник, преподаватель, административный сотрудник, аспирантура, магистратура, проектная работа, стажировка (D-134) | `position_type`: `research`, `teaching`, `admin`, `phd`, `masters`, `project`, `internship` |
| Научный работник | МНС, НС, СНС, ВНС, ГНС, заведующий лабораторией, инженер-исследователь, лаборант-исследователь, постдок | `position_type=research` |
| Преподаватель (ППС) | Профессорско-преподавательский состав: ассистент, преподаватель, старший преподаватель, доцент, профессор, заведующий кафедрой | `position_type=teaching` |
| Административный сотрудник | Методист, специалист учебного или научного отдела, грант-менеджер, трансфер технологий, руководитель ЦКП, декан, проректор | `position_type=admin` |
| Аспирантура, магистратура | Место в аспирантуре под тему и руководителя; набор на магистерскую программу | `position_type=phd`, `masters` |
| Проектная работа | Исполнитель по гранту, специалист проекта на срок проекта | `position_type=project` |
| Стажировка | Стажёр-исследователь, стажировка для студентов | `position_type=internship` |
| Специальность ВАК | Научная специальность из официальной номенклатуры; основа фильтра «область науки» | `specialty` |
| Степень | Кандидат наук, доктор наук (PhD — как эквивалент) | `degree` |
| Звание | Доцент, профессор | `title` |
| Карьерный уровень | R1 начинающий (аспирант), R2 признанный (молодой учёный, есть степень), R3 самостоятельный исследователь, R4 ведущий / руководитель; по образцу EURAXESS | `career_level` |
| Ставка | Доля занятости: 0,25 / 0,5 / 0,75 / 1 (в базе проценты) | `vacancies.rate_percent` |
| Источник финансирования | Бюджет, грант (РНФ и др.), хоздоговор, внебюджет | `funding_source` |
| Конкурс | Конкурсный отбор на должность ППС или научного работника; у вакансии отметка «конкурс» и дедлайн | `is_competition` |
| Дедлайн | Крайний срок подачи документов | `deadline` |
| Отклик | Заявка соискателя на вакансию | `application` |
| Статусы отклика | отправлен → просмотрен → приглашение → отказ / принят; плюс «отозван» (сам соискатель) | `sent`, `viewed`, `invited`, `rejected`, `accepted`, `withdrawn` |
| Приглашение | Собеседование (дата, время, ссылка / адрес), контакты, или просьба оставить контакты | `invitation` (`interview`, `contacts`, `request_contacts`) |
| Рекомендательное письмо | Пишет рекомендатель по одноразовой ссылке (текст и/или PDF); видит организация, не видит соискатель | `reference_letter` (вид файла), `reference_requests.letter_text` |
| Приватность профиля | скрыт / виден организациям / публичный + «открыт к предложениям» | `visibility` (`hidden`, `orgs`, `public`), `open_to_offers` |
| Близкий срок | Дедлайн не позже чем через 14 дней (включая сегодня): в интерфейсе отмечается жёлтым маркером; прошедший срок маркером не отмечается | `urgent` в `describeDeadline` (`web/src/lib/deadline.ts`) |
| Режим | «Ищу работу» или «Нанимаю»: переключатель одного аккаунта (D-004) | `role` (`seeker`, `employer`) в `web/src/features/shell` |
| Аккаунт | Один человек с почтой и паролем; роли «ищу / нанимаю» переключаются в режиме | `user` (`users`) |
| Сессия | Вход человека на одном устройстве, живёт в cookie до 30 дней | `session` |
| Одноразовая ссылка | Ссылка из письма для подтверждения почты или сброса пароля, срабатывает один раз | `auth_token` (`confirm_email`, `reset_password`) |
| Согласие на обработку ПДн | Галочка при регистрации (152-ФЗ); хранится дата и версия политики | `privacy_consent_at`, `privacy_policy_version` |
| Владелец | Роль в организации: управляет всем; в организации может быть несколько | `owner` (`org_members.role`) |
| Кадровик | Роль: ведёт вакансии и видит отклики всех подразделений | `hr` |
| Руководитель подразделения | Роль: ведёт вакансии и отклики только своих подразделений; подразделение закрепляется за ним отдельно | `unit_head`, `units.head_user_id` |
| Сотрудник | Человек с ролью в организации | `org_member` |
| Приглашение в организацию | Письмо со ссылкой на 7 дней: принять может аккаунт с той же почтой | `org_invitation` |
| Вид организации | Вуз, НИИ / институт РАН, научный центр, компания с R&D, технопарк, другое | `university`, `institute`, `science_center`, `rd_company`, `technopark`, `other` |
| Вид подразделения | Кафедра, лаборатория, отдел, ЦКП | `department`, `laboratory`, `division`, `shared_facility` |
| Научные темы подразделения | До 10 коротких фраз | `units.topics` |
| Адрес организации | Часть ссылки, из названия латиницей | `organizations.slug` |
| Вакансия | Позиция, которую организация открывает; поля зависят от типа позиции | `vacancy` (`vacancies`) |
| Статус вакансии | черновик → опубликована → закрыта → архив | `draft`, `published`, `closed`, `archived` |
| Должность | Запись справочника с типом позиции (МНС, доцент, аспирантура…) | `positions.code`, `position_code` |
| Область науки | Группа специальностей ВАК (1.4 Химические науки) или специальность (1.4.4); по ней ищут | `science_groups`, `specialties` |
| Что предстоит делать | Дисциплины (ППС), тема (аспирантура, постдок), проект (наука), сфера ответственности (управление) | `vacancies.focus` |
| Формат работы | Очно, гибрид, удалённо | `onsite`, `hybrid`, `remote` |
| Договор | Бессрочный или срочный (срок в месяцах) | `permanent`, `fixed`, `contract_months` |
| Жильё | Не предоставляется, общежитие, служебное жильё, компенсация аренды | `none`, `dormitory`, `service`, `compensation` |
| Стипендия | Деньги в вакансии вида «аспирантура», «магистратура», «стажировка» (те же поля, что зарплата) | `salary_from`, `salary_to` |
| Источник финансирования | бюджет, грант, хоздоговор, внебюджетные средства (+ уточнение, например номер гранта) | `budget`, `grant`, `contract`, `own`, `funding_note` |
| Куда можно создать вакансию | Организации целиком и отдельные подразделения, где человек вправе вести вакансии | `vacancy-targets`, `access.ManageVacancies` |
| Поиск по словам | Словоформы по-русски: «химия» находит «химии»; слова через пробел значат «и», `-слово` исключает | `q`, `vacancy_search` |
| Похожие слова | Запасной поиск с опечатками, когда точных совпадений нет | `fuzzy` |
| Срок договора (фильтр) | Бессрочный, срочный до года, до трёх лет, больше трёх лет | `term`: `permanent`, `short`, `medium`, `long` |
| Порядок выдачи | подходящие, новые, ближайший срок, большая зарплата | `sort`: `relevance`, `new`, `deadline`, `salary` |
| Просроченная вакансия | Опубликована, но срок подачи прошёл: в поиске её нет, страница по ссылке есть | D-066 |
| Профиль | Страница человека вместо резюме: должность, навыки, степень, звание, специальности, идентификаторы, публикации и др. | `profile` (`profiles`) |
| Навыки | Научные (методы, приборы, программы для исследований) и общие (компьютер, языки, работа с людьми); короткие фразы, до 30 в списке | `research_skills`, `general_skills` (`skills.research`, `skills.general` в ответе) |
| Режим приватности | Кому виден профиль: никому (скрыт), сотрудникам организаций, всем | `hidden`, `orgs`, `public` (`profiles.visibility`) |
| Сотрудник организации (для приватности) | Вошедший человек, состоящий хотя бы в одной организации, в любой роли | `privacy.Viewer.Staff` |
| Открыт к предложениям | Отметка в профиле: учёный не против приглашения на вакансию | `open_to_offers` |
| Записи профиля | Образование, опыт работы, публикации, гранты, патенты и программы, преподавание | `profile_items.kind`: `education`, `experience`, `publication`, `grant`, `patent`, `teaching` |
| ORCID, SPIN, Scopus ID, WoS ID | Идентификаторы учёного в международных и российской базах | `orcid`, `spin`, `scopus_id`, `wos_id` |
| h-index | Индекс Хирша по базе (РИНЦ, Scopus, Web of Science, Google Scholar), вводится вручную | `h_rsci`, `h_scopus`, `h_wos`, `h_scholar` |
| DOI | Номер научной публикации; по нему Crossref отдаёт название, авторов, журнал, год | `doi` (нижний регистр) |
| Резюме (CV) | PDF, который сервер собирает из профиля | `GET /api/profile/cv` |

| Снимок профиля | Копия профиля на момент отклика: организация видит именно её, даже если человек потом изменил или скрыл профиль | `applications.profile` |
| Почта для связи | Адрес, который соискатель указал в отклике; почта аккаунта организациям не показывается | `applications.contact_email` |
| Файл отклика | PDF: резюме из профиля (`cv`), приложенный файл (`attachment`), письмо рекомендателя (`reference_letter`); лежит в базе | `application_files` |
| Рекомендатель | Человек, у которого соискатель просит письмо; аккаунт не нужен | `reference_requests` |
| Просьба о рекомендации | Письмо рекомендателю с одноразовой ссылкой; ждём ответа / письмо получено / отказался | `pending`, `received`, `declined` |
| Одноразовая ссылка рекомендателя | `/recommend?token=`: 30 дней, срабатывает один раз (письмо или отказ); при повторной отправке прежняя перестаёт работать | `token_hash` |
| Уведомление | Запись в колокольчике (и такое же письмо на почту) о событии: новый отклик, письмо рекомендателя, отзыв | `notifications` |
| Очередь писем | Письма, которые ждут отправки в базе; отправитель повторяет при сбое | `outbox` |
| Решение по отклику | Принят или отказ; окончательное, с необязательной запиской кандидату | `decision_note`, `decided_by` |
| Просмотрен | Статус ставится сам, когда организация первый раз открыла карточку отклика | `viewed` |
| Собеседование (приглашение) | Дата и время по Москве, формат: онлайн (ссылка) или очно (адрес); соискатель подтверждает или предлагает другое время | `interview`, `place_kind` (`online`, `onsite`) |
| Состояния приглашения | ждёт ответа, подтверждено, предложено другое время, кандидат ответил, отправлено (контакты), отменено | `pending`, `confirmed`, `proposed`, `answered`, `shared`, `cancelled` |
| Ответ на приглашение | Один раз: подтвердить, предложить время, оставить контакты и удобное время | `confirm`, `propose`, `reply` (`AnswerInput.Action`) |
| Список откликов организации | Отклики на вакансии, которые человек вправе разбирать, с вкладками по статусам и отбором по вакансии | `/candidates`, `GET /api/my/candidates` |
| Соискатели (каталог) | Раздел «Соискатели»: список профилей, которые их владельцы открыли: публичные всем, «видны организациям» сотрудникам организаций; поиск, фильтры, порядок | `GET /api/scientists`, `privacy.CatalogModes` |
| Приглашение на вакансию | Организация зовёт конкретного учёного из каталога на конкретную вакансию (не путать с приглашением к отклику, D-090, и приглашением в организацию) | `offer` (`vacancy_offers`) |
| Состояния приглашения на вакансию | ждёт ответа, «Интересно», «Не сейчас», отозвано | `pending`, `interested`, `declined`, `cancelled` |
| Ответ на приглашение | «Интересно» или «Не сейчас», один раз, с необязательной запиской; отклик сам не создаётся | `AnswerInput.Action` (`interested`, `declined`) |
| Лучший h-index | Наибольшее из четырёх введённых значений (РИНЦ, Scopus, Web of Science, Google Scholar): в карточке каталога и в фильтре «h-index от» | `h_max` |
| Права «где вправе» | Организации целиком и подразделения, где человек вправе делать действие | `orgs.Scope`, `orgs.ScopeOf` |
| Избранное | Вакансии, которые человек отметил закладкой, чтобы вернуться; только опубликованные и закрытые, до 200 | `favorites`, `/favorites` |
| Сохранённый поиск | Слова и фильтры поиска вакансий под названием; о новых вакансиях по нему сообщают уведомлением и письмом; до 20 на человека | `saved_searches`, `/saved-searches` |
| Частота сообщений | Как часто писать о новых вакансиях по сохранённому поиску: сразу, раз в день (9:00 МСК), раз в неделю (понедельник), не сообщать | `instant`, `daily`, `weekly`, `off` (`matching.Frequencies`) |
| Подходящие вам | Подборка вакансий по профилю простыми правилами без ИИ: нужна общая группа специальностей ВАК, степень и звание не выше своих; баллы за точность специальности, уровень R, степень и регион | `matching.Score`, `GET /api/matches` |
| Причина подбора | Почему вакансия в подборке: совпала специальность, та же группа, уровень, степень, регион, удалённая работа | `reasons` (`specialty`, `group`, `level`, `level_near`, `degree`, `region`, `remote`) |
| Уровень по профилю | Оценка R1–R4 по степени и званию: без степени R1, кандидат R2, доктор R3, доктор и профессор R4 | `Profile.Level` |
| Напоминание о сроке | Уведомление и письмо за 7 и за 1 день до последнего дня подачи вакансии из избранного, если человек ещё не откликнулся | `deadline_reminders`, `matching.SendReminders` |
| Сроки (календарь) | Избранные вакансии по дате конца приёма заявок, по месяцам | `GET /api/deadlines`, `/deadlines` |
| Настройки писем | Два переключателя: письма о новых вакансиях и напоминания о сроках; письма об откликах и приглашениях отключить нельзя; уведомления на сайте остаются всегда | `notification_settings`, `/api/notification-settings` |
| Квартиль журнала | Четверть рейтинга журналов в своей предметной категории: Q1 — лучшие 25%. У нас «лучший квартиль» SCImago: лучший из квартилей журнала по всем его категориям | `journals.quartile` (1–4), `quartile` в ответах |
| Справочник журналов | Выгрузка SCImago Journal Rank (около 32 тысяч журналов, книжных серий и сборников) с квартилями и ISSN; заменяется целиком новым выпуском | `journals`, `journal_issns`, `scibox journals load` |
| ISSN | Номер периодического издания из 8 знаков (`1234-567X`, последний проверочный); у журнала их бывает два: печатный и электронный | `issn` (пакет `internal/issn`) |
| Журнал публикации | Журнал справочника, найденный по ISSN публикации; подставляется при чтении профиля | `Item.journal` |
| Статьи в Q1–Q2 | Публикации профиля в журналах первого и второго квартиля: всего и «за 5 лет» (текущий год по Москве и четыре предыдущих) | `quartiles` (`q12_total`, `q12_recent`, `recent_from`), фильтр `q12_min` |
