# Список частых паролей (срез 20, T-14, D-146)

`common-passwords.txt.gz` — пароли, которые сервер не принимает при регистрации, сбросе и смене пароля. Проверка идёт внутри сервера, пароль никуда не отправляется.

## Откуда

- Файл `Passwords/Common-Credentials/100k-most-used-passwords-NCSC.txt` из репозитория [danielmiessler/SecLists](https://github.com/danielmiessler/SecLists) (лицензия MIT, текст в `SECLISTS-LICENSE`). Список 100 000 самых частых паролей из утечек, собранный британским центром кибербезопасности (NCSC) по данным Have I Been Pwned.
- Скачан 2026-10-08: <https://raw.githubusercontent.com/danielmiessler/SecLists/master/Passwords/Common-Credentials/100k-most-used-passwords-NCSC.txt>, 835 538 байт, 99 840 строк, SHA-256 `c2e5696882c603b76bb67a47ee970897e5a76fc4c3f5547abe3d0ca340c576e0`.
- Русский список `sharsi1/russkiwlst` не взят: у него нет лицензии.

## Как получен файл

1. Записи `$hex[…]` раскодированы из шестнадцатеричного вида; русские пароли, испорченные двойной перекодировкой (UTF-8, прочитанный как cp1251), восстановлены.
2. Всё переведено в нижний регистр (проверка сравнивает без учёта регистра).
3. Оставлены только пароли длиной от 10 до 128 знаков и хотя бы с 5 разными знаками: более короткие и однообразные сервер и так не принимает (`ValidatePassword`).
4. Повторы убраны, строки отсортированы, файл сжат `gzip -9 -n`.

Итог: 8 923 пароля, 41 419 байт, SHA-256 `85e23e18e4c4e48cb51a447127c8c6ff587e4bef704e916fede5b5480133cfec`.

Сверх списка сервер проверяет свой короткий список (`extraCommonPasswords` в `breached.go`, русские и про сам сервис) и пароль, набранный в русской раскладке вместо английской («йцукенгшщз» = «qwertyuiop»).

## Как обновить

Скачать новый файл SecLists, повторить шаги 1–4 (скрипт в отчёте среза 20, `docs/slices/20-account-security.md`), заменить `common-passwords.txt.gz`, обновить размеры и отпечатки здесь. Тест `TestCommonPasswordList` проверит, что файл читается и в нём не меньше 8 000 паролей.
