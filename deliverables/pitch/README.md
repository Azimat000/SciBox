# Презентация ИОН для Бизнес-инкубатора ИТ-парка

Осенний отбор ИТ-парка 2026: заявки до 1 ноября 2026, финальный этап 11 ноября 2026. Форма заявки принимает PDF, DOC или DOCX до 20 МБ, поэтому подавать `ION-ITpark-2026.pdf`; на защите показывать `ION-ITpark-2026.pptx`.

| Файл | Что это |
|---|---|
| `ION-ITpark-2026.pptx` | Презентация: 17 слайдов основной части и 3 в приложении, заметки докладчика к каждому слайду |
| `ION-ITpark-2026.pdf` | Та же презентация для формы заявки |
| `rech.md` | Речь к защите из заметок докладчика, около 5,5 минуты |
| `review.md` | Проверка скиллом `pitch-deck-reviewer`: оценка и что доделать до подачи |
| `build.js`, `assets/` | Сборщик и картинки: логотип, фото, скриншоты настоящего сайта с демо-данными |

## Как пересобрать

Нужен Node.js. Фото команды лежат в `assets/`: `marat.jpg` и `azamat.jpg` для слайда команды, `marat-sq.jpg` и `azamat-sq.jpg` для титула. Если файла нет, сборщик ставит инициалы.

```bash
cd deliverables/pitch
npm install
npm run build
```

Палитра бренда записывается в тему файла, если указать папку скилла pptx: `PPTX_SKILL_DIR=… NODE_PATH=$PWD/node_modules npm run build`. Без этого презентация выглядит так же.

PDF из готового файла: открыть .pptx в PowerPoint и «Сохранить как PDF», или `soffice --headless --convert-to pdf ION-ITpark-2026.pptx`.
